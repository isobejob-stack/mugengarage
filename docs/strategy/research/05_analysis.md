# 調査5：分析のまとめ

作成：2026-10-31
目的：調査1〜4をまとめ、何が課題で、どこに機会があるかを整理する。現在の戦略（[../strategy.md](../strategy.md)）がどの課題に対応しているかも示す。

## 1. 課題の整理

**問い：日本のクラシックJaguarは、なぜミニやロードスターのように愛好家の輪が広がっていないのか。**

| 区分 | 課題 | 根拠 | 店1軒で対応できるか |
|---|---|---|---|
| A. 新しい人が来ない | 若い世代との接点がない | 調査1：若い世代の接点はYouTubeとInstagram | できる |
| | 「壊れる」「年配の人の車」という印象 | 調査4：V5、V7 | できる |
| | 維持費と相談先が分からない | 調査4：分かること2 | できる |
| B. オーナーが続かない | 購入後1年目の想定外の故障で手放す | 調査4：V5 | できる |
| | 相談できる相手や、同じ車のオーナーとの接点がない | 調査2：オーナーの集まりが見えにくい | できる |
| C. 良い車が次の人に渡らない | 整備記録や来歴が残っておらず、価値が正しく評価されない | 調査2：記録の揃った車が値を保つ | できる |
| | 安い個体が、整備されないまま流通する | 調査2：中古価格 | できる |
| D. 店1軒では変えられない | 旧車の税金の重課、保険の補償額の低さ | 調査1：日本市場の特徴 | できない |
| | 整備士の高齢化と不足 | 調査1 | できない |

A〜Cは店1軒で対応できる。Dは業界全体の課題で、3名体制の今は対象外とする。

## 2. 文化的な価値と価格の差

| 車種 | 文化的な価値 | 国内の価格 |
|---|---|---|
| Eタイプ | 世界的に知られた名車 | 高い（Jaguar Classicが当時の仕様にレストアした車は£28.5万〜） |
| XJ（X300など）、XJS | 従来の形のJaguarの最後の世代 | 100〜250万円台が中心 |

- XJやXJSは、知名度や歴史に比べて価格が低い。
- ただし、値上がりを狙うのは避ける。価格が上がりすぎると、若い人が買えなくなる（調査3：Z1/Z2）。
- 価格に差がつくのは「記録のある車」と「記録のない車」の間。整備記録や来歴を残せるのは、整備を担う専門店。

## 3. 成功例に共通する要因と、Jaguarの現状

（◎ 強い　○ ある　△ 弱い　× ない）

| 要因 | 代表的な事例 | Jaguarの現状 | 伸ばせる余地 | 現在の戦略で使うか |
|---|---|---|---|---|
| 「もう作られない」 | SR400、Z1/Z2 | ○ | ◎ | 使う（新型がEVに移り、従来の形は新車で買えない。ただし値上がりは宣伝に使わない） |
| 店が通い続ける拠点になる | H.O.G. | △ | ◎ | **使う（洗車で定期的に来てもらう）** |
| 車好き以外にも届く見せ方 | Luftgekühlt、Goodwood | △ | ◎ | 一部（インタビューで人の話を見せる） |
| 手の届く価格の入口 | Radwood、ロードスター | × | ◎ | 使う（XJ40、X300、XJSの動画） |
| 正直に見せることで生まれる信頼 | Bring a Trailer | × | ○ | **使う（父の点検コメントを動画で見せる）** |
| 無料の情報を入口にする | Hagerty | △ | ◎ | **使う（YouTube）** |
| 直し続けられるという見通し | マツダNAレストア | △ | ◎ | 使う（点検と整備の提案） |
| 専門店の連携 | ジャパンミニデイ | × | ○ | 使わない（3名体制では対象外） |

| 若い世代にとっての古いものの新しさ | アナログレコード、純喫茶 | △ | ○ | 使う（ショート動画） |
| 洗車動画による集客 | ビューティフルカーズ | × | ◎ | **使う（中心の施策）** |

## 4. 現在の戦略が対応する課題

| 課題（1章） | 洗車×インタビューでの対応 |
|---|---|
| 若い世代との接点がない | YouTubeの長尺動画とショート動画 |
| 「壊れる」という印象 | 実際のオーナーが、付き合い方と苦労を自分の言葉で話す |
| 相談先が分からない | 洗車で定期的に会い、父が点検結果を伝える |
| 購入後の想定外の故障 | 点検で気になる点を早めに見つけ、整備を提案する |
| 記録が残っていない | 動画、点検記録、インタビューが、その車の記録になる |
| 安い個体の流通 | 対応しない（今回の範囲外） |
| 税金、保険、整備士不足 | 対応しない（業界全体の課題） |
