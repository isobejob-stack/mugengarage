# 調査2：クラシックJaguarの状況

調査日：2026-10-30
目的：調査1の市場の中で、クラシックJaguarがどういう状況にあるかを把握する。

## 1. メーカー（JLR／Jaguar）の動き

| 時期 | 出来事 | 出典 |
|---|---|---|
| 2023年末 | F-TYPE、XF、XEの受注を終了。2025年からEV専売に移行すると発表 | MarkLines ほか |
| 2024年11〜12月 | リブランド「Copy Nothing」と新ロゴ、コンセプトカー「Type 00」を発表。旧来のファンから「名前だけのJaguar」などの強い反発 | CAR Magazine、Fortune、The Conversation |
| 2025年 | 新車のラインナップがほぼない状態。欧州の登録台数は2025年4月に前年比97.5%減の49台と報じられた | MarkLines（ACEAのデータを引用） |
| 2025年4月 | Jaguar Classic（古い車の部門）が、Eタイプのボディパネル約30点を新たに再生産 | GoAuto、Carscoops |
| 2026年5月 | 4ドアEVの名称を「Type 01」と発表（1,000hp級、約13万ドル〜） | evo、Autoblog |
| 2026年6月 | Jaguar ClassicのC/Dタイプのコンティニュエーション（復刻生産車）が日本で初めて展示された | as-web |

JLRの公式な説明は「創業者のウィリアム・ライオンズは、Jaguarは何の模倣でもあるべきではないと考えていた」「ヘリテージブランドではなく、ヘリテージを持つブランドだ」というもの。

**分かること**
- 新車のJaguarはEVに移り、従来の形のJaguarは新車では手に入らなくなった。
- メーカー自身もJaguar Classicの部品再生産や復刻車で、古い車の価値を事業にしている。
- 英国の論者は「リブランドで、人々はさらに古いJaguarに向かうだろう」と予想している（Heritage Car Insurance）。ただし、需要が増えたことを示す数字は、現時点で見つかっていない。
- 発信で新型を批判するのは避けた方がよい。新型を好む人もいる。

## 2. 国内の中古価格

| 車種 | 価格の目安 | 出典・注記 |
|---|---|---|
| XJ（X300系、1994年〜） | 平均約120〜130万円。走行5〜7万kmが多い。総生産92,038台 | Motor-Fan（2026年10月） |
| XJ（X300／X308） | 支払総額150万円前後の個体が多い（V8中心） | くるまのニュース |
| XJ（X350系） | 平均約150〜180万円（流通は30〜40台程度） | Motor-Fan |
| XJS | 英国で状態の良いクーペが個人売買で£5,000〜8,000、専門店の個体は£30,000超。「価値は上昇中」 | Honest John Classics |
| XJ全般（欧州） | 2024年〜2026年1月はおおむね横ばい。価値を決めるのは世代、エンジン、オリジナルかどうか。記録の揃ったオリジナル車は値を保つ | Classic Trader |

**分かること**
1. 入口の価格は低い。X300系なら100万円台前半から買える。
2. 安い個体ほど、先送りされた整備を抱えていることが多い。購入価格より整備費が高くつき、「Jaguarは壊れる」という評判につながりやすい。
3. 欧州では、記録の揃った車が値を保つ。整備記録や来歴が価格に影響する。

## 3. 部品と整備

- Jaguar Classicの純正部品の対象：X300（6気筒・12気筒）、XJS、シリーズ3 XJ12、XJ6、XJ8（X308）、XJ40、デイムラー・リムジン（1992年まで）。
- シリーズ3のXJとXJSで、2万1,000点を超える部品番号と当時の図面がある。
- 回収した金型300点以上で、XJSのボンネットなどを再生産した。ただし「どの車種でも100%の部品供給は現実的ではない」（2017年 JEC総会議事録）。
- 公式のeBayストアなどで、純正部品を買いやすくなっている（2023年）。

**分かること**：部品はある程度手に入る。より不足しているのは、組み付けて調子を見られる整備士と、診断の知識。

## 4. 国内のオーナーの集まり

- 「ジャガー・カー・クラブ・オブ・ジャパン」が2005年に横浜赤レンガ倉庫で「ジャガー・デイ2005」を開催した（約100台）。現在の活動は外から確認できなかった。
- フェラーリやミニに比べると、クラシックJaguarのオーナーが集まる場や、発信する人は少ない。
- 英国では、Jaguar Enthusiasts' Clubが会員1万5,000人超（同クラブの発表）、Jaguar Drivers' Clubが約5,000人（2022年）。

## 5. 強み・弱み・機会・脅威

| 区分 | 内容 |
|---|---|
| 強み | デザイン（Eタイプ、XJ）、英国車のイメージ、手頃な入口価格（X300、XJS）、30年の整備の知識、メーカーによる部品の再生産 |
| 弱み | 「壊れる」「年配の人の車」という印象。オーナー同士のつながりが少ない。発信する人が少ない。国内のオーナー数が少ない |
| 機会 | リブランドで、従来の形のJaguarは新車で買えなくなった。若い世代の関心。国産旧車の高騰で、輸入クラシックが相対的に割安。記録を重視する市場の流れ |
| 脅威 | 旧車の税金の重課。整備士の高齢化。安い個体による悪評。新型Jaguarとの混同 |
