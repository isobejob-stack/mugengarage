# 調査1：市場構造（世界と日本）

調査日：2026-10-30
目的：クラシックカーの市場で、お金と関心がどこに集まっているかを把握する。
注意：数字は出典ごとに定義が違うため、出典と組にして扱う。

## 1. 世界市場の規模と動き

| 指標 | 数字 | 出典・注記 |
|---|---|---|
| オークション＋オンラインの取引額（2025年） | 約48億ドル（前年比+10%） | Hagerty（CNBC、2025-12-19）。米国中心 |
| うちオンライン | 約25億ドル（+12%）。全体の半分を超える | 同上 |
| Bring a Trailer（オンラインオークション）の取引額（2025年） | 約17.1億ドル。出品49,486件、落札率81%、登録ユーザーは1年で25.5万人増 | Bring a Trailerの発表（The Shop、CarPro） |
| Bring a Trailer の取引額の推移 | 2023年 約14億ドル → 2024年 約15億ドル → 2025年 約17.1億ドル | CNBC、Jalopnik、The Shop |
| 調査会社による「市場規模」の推計 | 386〜408億ドル（2025年） | 方法論が不明なため参考値 |
| Hagertyの市場レーティング | 2026年1月 58.28（約15年ぶりの低水準）→ 59.01 | 「相場は横ばい」の水準 |
| Hagerty Hundred（よく保険がかけられる旧車の価値指数） | 2022年をピークに緩やかに下落 | Motorious |

**分かること**
1. 取引の中心は、会場でのオークションからオンラインに移っている。
2. 最高価格帯は好調だが、1960〜70年代の一般的な旧車は相場が下がっている。1990年代以降の車が上がっている。
3. 相場の指数は横ばいだが、取引件数と参加者は増えている。値上がりを期待して買う人より、乗りたい人の比率が増えていると考えられる。

## 3. 日本市場の特徴

| 項目 | 事実 | 戦略への影響 |
|---|---|---|
| 旧車の税金が重い | 自動車税は初度登録から13年超で約15%増（ディーゼルは11年超）。重量税は13年超と18年超の2段階で増える。HVとEVは対象外 | 維持費の高さの一部は制度による |
| 車を長く使う傾向 | 乗用車の平均車齢は9.44年（2025年3月末、31年連続で過去最高）。平均使用年数は13.35年 | 古い車に長く乗ることは、社会の流れと合っている |
| 国産旧車の海外流出 | 米国の25年ルールで、右ハンドルの国産スポーツカーが米国へ流出し、国内の価格が上がった | 国産旧車は若者の手が届きにくくなった。輸入クラシックは相対的に割安 |
| 整備士の不足 | 若者の志望が減り、整備要員の平均年齢が上がっている。整備業者の倒産も増えている | 古い車を直せる人が減っている。専門店の技術の価値が上がる |
| 車種別のオーナーの集まり | ジャパンミニデイ（浜名湖）は約3,000台で過去最多。主催はミニ専門店の団体JMSA | 専門店が集まれば、大きな集まりを作れる例 |

## 4. 市場の構造

```
[供給]          [流通]               [所有の支援]          [情報・文化]
現存する車  →  専門店              → 整備・レストア      → 動画・雑誌
部品        →  一般の中古車店      → 保険                → イベント・クラブ
整備士      →  オークション        → 保管・税金・車検    → 車の記録
            →  個人売買・輸出入
```

- 売上が立つのは左側（販売・整備）。買いたい人を増やすのは右側（情報・文化）。
- 米国のHagertyは、保険、動画、会員制度、相場情報、売買の場をまとめて提供し、右側から左側の需要を作っている。
- 日本のクラシックJaguarには、右側の担い手がほとんどいない。
