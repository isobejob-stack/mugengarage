# Step 07 — 戦略の改訂：3人で回す「洗車×オーナーズインタビュー」

> 改訂日：2026-10-31。発注者のフィードバックを受けて、Step 06 の戦略を実際の体制に合わせて絞り込む。
> 企画の詳細は `kit/S10_wash_interview_series.md`。

## 7-1. 前提の変更

| 項目 | Step 06 の想定 | 実際 |
|---|---|---|
| 運営の人数 | 明記していなかった（施策を多く並べた） | **実質1〜3名** |

## 7-2. やめるもの・凍結するもの

| 施策 | 判断 | 理由 |
|---|---|---|
| 維持費ガイドの公開（P-1） | **撤回**（ページを削除） | 公開した金額より実際の費用が上ぶれすると「書いてあった額と違う」と信頼を損なう。数字は1対1の相談で、個体ごとの見積もりと一緒に伝える |
| 朝の集まり（月1回）・Grand Tour | **撤回** | 忙しいオーナーにはメリットが薄く、少人数の運営には負担が大きい |
| LINEオープンチャットのサークル | **撤回** | 公式LINEの1対1で十分。場の管理に人手を割かない |
| 英国クラシック連合イベント、レジストリ、相場レポート、制度提言 | **凍結** | 3人では手が回らない。来歴の記録は、洗車とインタビューの記録で自然にたまる |
| 12週間のコンテンツ計画（S-6） | **置き換え** | 洗車×インタビューのシリーズ（S-10）に一本化する |
| はじめてのJaguarパッケージ（S-8） | 保留 | 洗車シリーズで接点が増えてから考える |

残すもの：オーナーズインタビュー（S-2の同意書と質問）、N1インタビュー（S-1。洗車の受け渡しの時間を使う）、トーン＆マナー（S-7）、整備と部品のページ、オーナーの声、購入前の開示。

## 7-3. 新しい中核：1回の洗車で5つの仕事をする

**「徹底洗車」を入口にして、撮影、インタビュー、点検、関係づくりを1回の来店にまとめる。**

```
        ┌─────────────── 洗車の予約（3万円〜）───────────────┐
        │                                                     │
        ▼                                                     │
 ① 徹底洗車（父・兄）──→ ② 撮影（兄）──→ ③ 動画公開（兄）──→ 新しいオーナーが見て申し込む
        │                    │
        │                    └─→ 愛車紹介とインタビュー（父が聞き手）
        ▼
 ④ 洗いながら車を細かく見る（父）──→ 整備の提案（押し売りしない）
        ▼
 ⑤ 記録（車の状態・話したこと・次に乗りたい車）──→ 3〜4ヶ月後に次の洗車の案内
                                                    └─→ 合う車が入ったら個別に連絡
```

| 仕事 | 何が起きるか | 担当 |
|---|---|---|
| ① 売上 | 洗車そのものが有料サービス | 父・兄 |
| ② コンテンツ | 車系YouTubeの強いジャンル（ビフォーアフター、作業の音）×成功者インタビュー＝**2段構造** | 兄 |
| ③ 点検と整備の接点 | 洗えば車の隅々まで見える。オイル漏れ、ゴムの劣化、錆。売り込みではなく「気づいたことの報告」になる | 父 |
| ④ 来歴の記録 | その時点の車の状態が映像と写真で残る。売却・継承のときの証拠になる | 兄（撮影）・父（所見） |
| ⑤ 接触回数 | 洗車は繰り返し使える。インタビューは1回きりでも、洗車は季節ごとに来る理由になる | 本人（CRMと案内） |

**ユーザーの最初の3つの狙いとの対応**
- 憧れを作る → 仕上がった車と、オーナーの生き方が映像に残る
- 成功者の印象 → 「どんな人がこの車に乗っているか」が自然に伝わる（成功を語らせなくても、車と言葉で伝わる）
- 顧客の安定 → 洗車で年に3〜4回会う関係ができる。乗り換え・買取・紹介の相談が、営業をかけなくても生まれる

## 7-4. なぜこの形が強いか（Step 03 の型との対応）

| 型 | この企画での現れ方 |
|---|---|
| ⑤ 集合知と信頼（Bring a Trailer） | 洗車中の父の所見を、動画で正直に見せる。良いところも、気になるところも |
| ⑥ 無料の接点（Hagerty） | 動画は無料の入口。洗車という「小さな有料の入口」があるのが強い（いきなり車を売らない） |
| ② 所属（H.O.G.） | 集まりではなく、**「この店に車を預けている」こと自体が所属**になる |
| ⑨ 感覚の記号（アルファ） | 洗車の過程でウッド、レザー、塗装の深さを映像で見せられる |
| ⑩ アナログの新しさ | 手作業の洗車はショート動画と相性がよい（作業の音、泡、ビフォーアフター） |

業界の解説でも、ディテイリングの作業動画は「ビフォーアフターの差が分かりやすく、作業音や道具への関心も高いため、YouTubeと相性が良いジャンル」とされている。国内にも近い先例がある。秋田市の洗車・コーティング専門店「ビューティフルカーズ」（運営会社は社員10人ほど）は、「BeautifulCars洗車チャンネル」の登録者が約10万人、最も見られた動画は225万回以上で、**全国の車好きが秋田まで訪ねてくるようになった**と報じられている（PRESIDENT Online）。少人数でも、洗車動画で遠方から客を呼べることを示す例。

## 7-5. 決めてほしいこと（企画書 S-10 の8章と同じ）

1. 洗車メニューの範囲と価格（3万円の中身）
2. 出演特典を「値引き」にするか「追加作業」にするか
3. 預かり中の事故に備える保険の確認
4. 対象をJaguarと英国車に絞るか、ハイクラスの旧車全般に開くか
5. 最初の出演者3名（父のお得意様から）
