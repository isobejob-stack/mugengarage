# 調査の要約（戦略の根拠）

調査日：2026-10-30〜31
対象：公開されている記事、統計、企業の発表。数字は出典ごとに定義が違うため、出典と組にして扱う。

## 1. 要点

1. 世界のクラシックカー取引は、オンラインの比率が高まっている。若い世代の関心も高く、主な接点はYouTubeとInstagram。
2. Jaguarは新車をEV専業に切り替え中で、旧来のファンの反発が強い。一方、XJやXJSの中古価格は100〜250万円台が中心で、手に入れやすい。
3. 洗車動画は再生されやすいジャンルで、少人数の洗車専門店が動画で全国から集客した例がある。
4. オーナーの声からは、購入のきっかけは「見た目に惚れた」「人に勧められた」が多い。手放す理由は「想定外の故障」と「相談先がない」ことが目立つ。
5. 車の記録（整備歴や来歴）が揃った個体は、価値を保ちやすいと報告されている。

## 4. 参考になる事例

| 事例 | 事実 | この戦略への示唆 |
|---|---|---|
| ビューティフルカーズ（秋田の洗車・コーティング専門店） | 運営会社は社員10人ほど。「BeautifulCars洗車チャンネル」の登録者は約10万人、最も見られた動画は225万回以上。全国の車好きが秋田まで来店するようになった | 少人数でも、洗車動画で遠方から集客できる |
| ディテイリング（徹底洗車）の作業動画 | ビフォーアフターの差が分かりやすく、作業音や道具への関心も高いため、YouTubeと相性が良いとされる | 1段目（集客）の動画に洗車を使う根拠 |
| Bring a Trailer | 2025年の取引額は約17.1億ドル。コメント欄で専門家が車の状態を検証し、出品者が質問に答える文化がある | 良い点も気になる点も正直に見せる方が、信頼につながる |
| Hagerty（米国の旧車保険会社） | 無料の動画（YouTube登録者300万人超）や相場ツールを入口にし、利用者が保険の加入につながる仕組みを株主に説明している。YouTube視聴者の最大層は40歳未満 | 動画は費用ではなく、お客様を集める手段 |
| Harley-Davidson H.O.G. | 1983年に始まったオーナーの会。新車の購入で1年間自動入会し、販売店が地域の拠点になった。2023年時点で約68万人 | 店が「いつでも相談できる場所」になることが、関係を続ける土台になる |

## 6. 調査の限界

- 世界市場の数字は米国の取引が中心。
- この環境の通信制限で、個別ページの本文を取得できなかった。オーナーの声は検索結果に表示された範囲から集めている。
- リブランドによって古いJaguarの需要が増えたことを示す数字は、見つかっていない。
- 国内のクラシックJaguarの現存台数やオーナーの年齢構成には、公的な統計がない。
