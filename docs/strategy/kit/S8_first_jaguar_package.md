# S-8 「はじめてのJaguarパッケージ」商品設計書

> 目的：初めての人が安心して入れる「入口」を作る（熱源④未評価世代への旗、⑦直し続ける宣言）。
> 狙う人：P2 乗り換えの実力者、P1 憧れの若手（`docs/strategy/04`）。
> 解決する不安：「いくらかかるか分からない」「誰に相談すればいいか分からない」（I-2）、「1年目の想定外で離脱」（V5）。
> **価格はすべて店が決める。** この設計書は、構成と考え方のたたき台。

## 1. 対象車種（案）

| 車種 | 選ぶ理由 | 店の確認 |
|---|---|---|
| X300 XJ6（3.2／4.0） | 最後の直列6気筒（AJ16）。流通量が比較的多く、相場は平均120〜130万円前後（Motor-Fan 2026年10月） | 対象にするか |
| XJ40 | 手頃な入口。角目／丸目の個性 | 同上 |
| XJS（4.0） | クーペの美しさ。V12より維持の見通しが立てやすい | 同上（V12を対象にするか） |

## 2. パッケージの中身

| 要素 | 内容 | 不安への効き方 |
|---|---|---|
| ① 車両 | 店が仕入れ、状態を把握している個体 | 「どの車を選べばいいか」 |
| ② 納車整備 | 予防整備の計画（S-3 2-2）のうち、初年度に必要なものを実施 | 「買ってすぐ壊れる」 |
| ③ 整備記録の引き継ぎ | 店が把握している過去の整備記録と、今回の整備内容を1冊に | 来歴（B4）の始まり |
| ④ 予防整備の計画書 | 今後3年で必要になりそうな整備と、費用の幅 | 「いくらかかるか分からない」 |
| ⑤ 1年目の伴走 | 1ヶ月・3ヶ月・6ヶ月・12ヶ月の点検（無料または定額）。LINEでの相談はいつでも | 「誰に相談すればいいか」「1年目の離脱」 |
| ⑥ オーナーズサークルへの招待 | 納車時にカードを渡す（S-4） | 孤独 |
| ⑦ 手放す時の約束 | 将来手放す時は、店が来歴ごと査定する（買取・委託販売） | 「手放す時に買い叩かれる」 |

## 3. 価格の示し方

- **「車両価格」ではなく「1年目の総額」で示す。** 車両＋納車整備＋1年目の伴走＋法定費用（S-3 1-4）。
- 2年目以降の目安（定額メンテナンスプラン B3 に入った場合／入らない場合）を並べて見せる。
- 例（数字はすべて店が記入）：

| | X300 XJ6 4.0 |
|---|---|
| 車両価格（税込・諸費用込） | 店で記入 |
| 納車整備 | 店で記入（パッケージに含む） |
| 1年目の伴走（点検4回） | 店で記入（パッケージに含む） |
| 法定費用（年額） | 約11.1万円（S-3） |
| 任意保険（参考） | 見積例を記入 |
| **1年目の総額の目安** | 店で記入 |
| 2年目以降の年額の目安 | 店で記入 |

## 4. 売り方

- 公開サイト：維持費ガイド（P-1）と「直し続ける」ページ（P-4）から、パッケージ対象の在庫へつなぐ。
- 動画：A-1「最後の直列6気筒」、A-2 長尺「維持費を全部見せます」の最後で紹介する（S-6）。
- 試乗・見学：朝の集まりの見学枠（S-4）から、店への来店につなぐ。
- **値上がりを売り文句にしない**（S-7）。

## 5. 店に決めてほしいこと

1. 対象車種と、対象にする個体の基準（走行距離、整備歴、ボディの状態）。
2. 納車整備の標準メニューと価格。
3. 1年目の伴走の回数と、無料／定額の別。
4. 「手放す時の約束」の範囲（買取価格の考え方、委託販売の手数料）。
5. パッケージの名前（「はじめてのJaguar」は仮）。

## 6. 測る指標

- パッケージへの問い合わせ数、成約数。
- 成約者のペルソナ（P1・P2の比率）。
- **1年以内に手放した人の数**（目標：限りなくゼロ）。
- 1年目の伴走の完了率、2年目以降の定額プランへの移行率。
