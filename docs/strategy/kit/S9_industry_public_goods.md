# S-9 業界の公共財の設計書

> 目的：一店舗では動かせない壁（税制、整備士不足、母数の小ささ）に、界隈全体で向き合うための「公共財」を作る。
> 原則：**独立した名前で運営し、運営者がエムガレージであることを必ず明記する。自社在庫への誘導はしない。他店の個体も平等に扱う。**（ステマ規制の遵守と、界隈からの信頼のため）
> 商標：「Jaguar」はJLRの登録商標。名称に使う場合は公式と誤認されない表現にし、必要なら権利者に確認する。

## I1. クラシックJaguarレジストリ（国内現存車の台帳）

**なぜ作るか**：国内に何台残っているかを示す公的な統計がない。台帳は「来歴が価値を決める」市場（`docs/strategy/05` 5-2）の基盤であり、制度への働きかけ（I5）の根拠にもなる。海外では車種別クラブが同様の台帳を持つことが多い。

| 項目 | 設計 |
|---|---|
| 名前（仮） | Japan Classic Jaguar Register（日本クラシックJaguar登録簿） |
| 登録できる人 | 現オーナー（任意。店で買った車に限らない） |
| 登録する情報 | 車種、年式、車台番号（**公開は下4桁のみ**）、外装色・内装色、仕様、初度登録の地域（都道府県まで）、オーナーの数（分かる範囲）、主な整備・レストアの履歴、写真 |
| 公開しない情報 | 氏名、連絡先、住所、ナンバー、完全な車台番号 |
| 公開の仕方 | 車種別・年式別の台数の集計と、オーナーが公開を選んだ個体のページ |
| 運営 | エムガレージ（明記）。将来は連合（I3）の共同運営に移すことを目指す |
| プラットフォームとの関係 | オーナーズアーカイブ（FR-OWN）を拡張して実装できる。最初はフォーム＋スプレッドシートで小さく始める |

**最初の一歩**：自社で販売・整備した車から、オーナーの同意を得て登録する（目標：初年度50台）。

## I2. クラシックJaguar相場・維持費レポート（四半期ごと）

| 項目 | 設計 |
|---|---|
| 内容 | 車種別の流通台数と価格帯（公開されている中古車情報の集計）、自社の成約データ（個体が特定されない形）、維持費の目安（S-3）、海外の動向（Hagertyなど） |
| 使わない言葉 | 「買い時」「値上がり確実」（S-7） |
| 形式 | サイトのブログ記事（カテゴリ：レポート）＋短い動画 |
| 狙い | 界隈の「基準」になる（Hagertyの相場ツールの役割）。検索からの流入 |

## I3. 英国クラシック連合イベント

| 項目 | 設計 |
|---|---|
| 参考 | ジャパンミニデイ（ミニ専門店の団体JMSAが主催し、約3,000台。ミニ以外の英国車も参加可能） |
| 名前（仮） | British Classic Morning（英国クラシックの朝） |
| 共催の候補 | 近隣の英国車専門店（ミニ、ローバー、ロータス、MGなど）、各車種のオーナーズクラブ |
| 規模 | 初回は50〜100台。Jaguarは主役級の一角 |
| 内容 | 車の展示と交流。英国のドレスコードを推奨（Goodwood Revival型。強制はしない）。整備の公開相談コーナー。若い世代の見学枠 |
| 準備の順番 | ①朝の集まり（S-4）を半年続けて実績を作る → ②近隣の専門店に声をかける → ③会場と日程を決める（1年目の後半〜2年目） |

## I4. 技術の継承

- 若手整備士・整備学校の学生向けの公開講座（年2回、旧車の基本：キャブレター、電装、冷却系）。
- 整備の知見をサイトの図鑑・ライブラリに少しずつ書き起こす（30年の知識のデジタル資産化。プロダクトゴール3と一致）。

## I5. 制度への働きかけ

- 論点：旧車の重課（自動車税13年超、重量税13年・18年超）、車両保険の協定価額が市場価値と大きく乖離していること。
- 方法：一店舗で声を上げても届かない。連合（I3）やオーナーズクラブ、既存の業界団体と組み、レジストリ（I1）のデータ（台数、平均の年間走行距離、保管の状況など）を根拠にする。
- 時期：2〜3年目。まずはデータを集めることが先。
