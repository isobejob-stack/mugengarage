# S-1 N1インタビューキット

> 目的：30年分の顧客から「なぜ買い、なぜ去り、なぜ語るのか」を一次情報として集め、戦略（`docs/strategy/04`）の仮説を検証する。
> 所要：1人あたり30〜45分。最初の4週間で15〜20名。
> 担当：店長（聞き手）＋記録係1名（いなければ録音して後で書き起こす）。

## 1. 誰に聞くか（候補の選び方）

各カテゴリから3〜5名。**偏りを避けるため、仲の良い常連だけで埋めない。**

| カテゴリ | 条件 | 何を知りたいか | 人数 |
|---|---|---|---|
| A 乗り換え組（P2） | ドイツ車やスポーツカーから乗り換えてきた人 | 何がきっかけで、何を決め手に乗り換えたか | 3〜5 |
| B 長年のオーナー（P4） | 5年以上所有している人 | なぜ続いているか。誇りを感じる瞬間 | 3〜5 |
| C 帰ってきた愛好家（P3） | 昔乗っていた、または若い頃に憧れていた人 | 若い頃の記憶と、今買う理由 | 2〜3 |
| D 手放した元オーナー | 1〜3年以内に手放した人 | **離脱の本当の理由**（最重要。聞きにくいが価値が高い） | 2〜3 |
| E 買わなかった検討者 | LINE相談や来店をしたが、購入しなかった人 | 何が障壁だったか | 2〜3 |
| F 若い世代（P1） | 20〜30代のオーナー、または真剣な検討者 | 遭遇の経路、周囲の反応 | いれば全員 |

**CRMからの抽出方法（M-GARAGE Platform）**
- 管理画面 > 顧客 で「購入履歴あり」「最終来店日」を見て A・B・C を選ぶ。
- 「売却相談」のタイムラインがある顧客から D を選ぶ。
- 問い合わせ一覧で「購入相談」かつ購入に至っていない人から E を選ぶ。

## 2. 依頼の仕方

### LINE・メールの依頼文（例）

> ○○様
> いつもエムガレージをご利用いただき、ありがとうございます。
> 今、これからJaguarに乗る方のために、オーナーの皆さまが「なぜJaguarを選び、どう付き合ってこられたか」をお聞きしています。
> 30分ほど、お茶を飲みながらお話を聞かせていただけませんか。店頭でも、お電話でも構いません。
> お聞きした内容は店の中だけで使い、お名前が外に出ることはありません（動画やサイトへの掲載は、別途ご相談のうえ、ご了承いただいた場合だけです）。

### 手放した方・買わなかった方への依頼文（例）

> ○○様
> 以前はご相談いただき、ありがとうございました。
> 私たちのサービスを良くするため、率直なご意見をうかがえないでしょうか。
> 「こうだったら続けていた」「ここが不安だった」という声こそ、いちばん参考になります。お叱りも歓迎です。15分ほどで構いません。

**謝礼**：オイル交換1回分、店のオリジナルグッズなど、店の負担が小さく関係が続くものにする。現金は避ける（関係が取引になる）。

## 3. 質問ガイド

**原則**
- 「なぜ？」を3回まで掘る。抽象的な答え（「かっこいいから」）で止めない。「どこが？」「いつそう感じた？」と具体に降りる。
- **誘導しない。** 「維持費は大変でしたか？」ではなく「買う前に一番怖かったことは？」と聞く。
- 相手の言葉をそのまま書き留める。要約は後で。
- 店の説明や反論はしない。今日は聞く日。

**質問（共通）**

| # | 質問 | ねらい | 掘り下げの例 |
|---|---|---|---|
| Q1 | 初めてJaguarを意識した瞬間は、いつ、どこで、誰といた時ですか？ | 遭遇の経路 | その時、何が目に入りましたか？ |
| Q2 | 買う前に、一番怖かったことは何でしたか？ | 障壁 | それはどうやって解消しましたか？（しなかった？） |
| Q3 | 他に検討した車はありますか？ なぜJaguarに決めましたか？ | 比較と決め手 | 最後の一押しは何でしたか？ |
| Q4 | 実際に持ってみて「想像と違った」ことは？ | 期待と現実の差 | 良い意味では？ 悪い意味では？ |
| Q5 | ご家族や友人の反応はどうでしたか？ | 周囲の受け止め | 今は変わりましたか？ |
| Q6 | この車のことを、誰かに話したくなるのはどんな時ですか？ | 語りのきっかけ | 最近、誰に話しましたか？ |
| Q7 | 手放すとしたら、どんな人に乗ってほしいですか？ | 継承の意識 | その人に何を伝えたいですか？ |
| Q8 | 20代の自分に、この車のことを何と伝えますか？ | 若い世代への言葉 | （インタビュー動画の候補になる） |

**カテゴリ別の追加質問**

- D（手放した人）：手放そうと決めた「最後の出来事」は？ / その時、誰かに相談しましたか？ / 何があれば続けていましたか？ / また乗りたいと思いますか？
- E（買わなかった人）：最後に何が引っかかりましたか？ / 代わりに何を買いましたか？ / どんな情報があれば決められましたか？
- F（若い世代）：どこでJaguarを知りましたか（SNS、映画、街中、家族）？ / 同世代の反応は？ / 毎月いくらまでなら車にかけられますか？

## 4. 記録シート

1人1枚。CRM（顧客タイムラインのメモ、FR-CRM-003）にも同じ内容を残す。

```

車種・年式：                   所有期間：
年代：                         以前の車：

■ 発言の記録（言葉そのまま。印象的な一言には ★）
Q1:
Q2:
...

■ タグ（該当するものすべて）
[動機]  一目惚れ / 人の勧め / 家族の記憶 / 美意識 / 人と違う / 音・匂い / その他(   )
[不安]  維持費 / 故障 / 相談先 / 家族の理解 / 手放す時 / その他(   )

■ 動画出演の打診：可 / 不可 / 要相談
```

## 5. まとめ方（4週間後）

1. 全員分の★の発言を1枚に並べる。
2. タグの数を数え、**「動機」「不安」「離脱」の上位3つ**を出す。
3. `docs/strategy/04_user_insights_n1.md` の仮説（I-1〜I-5）と照らし合わせ、合っていた点と違っていた点を書く。
4. 違っていた点は、戦略（`06_strategy.md`）のどの施策に影響するかを書く。
5. 結果は `docs/strategy/kit/S1_results_YYYYMM.md` として残す。

**検証したい仮説（優先順）**
- I-2 不安の正体は「いくらかかるか、誰に相談すればいいか分からない」ことか？
- I-1 離脱は「想定外」と「相談先の不在」で起きるか？（Dの人で検証）
- I-3 若い人は比較せず「遭遇」で決めるか？（Fの人で検証）
- I-5 「成功者らしさ」は美意識と手間から生まれるか？（A・Bの人で検証）
