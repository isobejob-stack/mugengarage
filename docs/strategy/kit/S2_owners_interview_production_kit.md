# S-2 オーナーズインタビュー撮影キット

> 目的：オーナーの美意識と生き方を映し、「憧れ」「成功者の印象」「来歴」を同時に作る。
> 形式：1回の撮影（60〜90分）から **長尺1本（5〜10分）＋ショート3〜4本（各30〜60秒）** を作る。
> 原則：**成功を語らせない。生き方を映す。** 見せるのはお金ではなく、手間を惜しまない美意識。

## 1. 撮影前の準備

| 項目 | 内容 |
|---|---|
| 出演の確認 | 許諾書（本ファイル5章）に事前に目を通してもらう。顔出しの有無を決める |
| 顔出しの選択肢 | ①顔出し ②後ろ姿・手元のみ ③声のみ（映像は車だけ）④テロップのみ |
| 職業の出し方 | 一行のテロップだけ（例：「建築設計」「飲食店経営」）。会社名は出さない |
| 場所 | 本人の職場、行きつけの場所、走りたい道。**自宅は避ける**（場所の特定を防ぐ） |
| 車 | 洗車済み。ナンバーは撮影時に隠すか、編集でぼかす |
| 機材 | スマホ2台（正面と横）、ピンマイク、三脚。縦（ショート用）と横（長尺用）を同時に撮る |

## 2. 構成と質問

聞き手は画面に出ない。質問はテロップで入れる。

| 順 | パート | 質問 | 使い道 |
|---|---|---|---|
| 1 | 導入 | 何をされている方ですか？（一言で） | テロップのみ |
| 2 | 仕事 | 仕事で一番大事にしてきたことは何ですか？ | ショート① |
| 3 | 選んだ理由 | 新しい車ではなく、この車を選んだ理由は？ | ショート② |
| 4 | 付き合い方 | この車とは、どう付き合っていますか？（手入れ、乗る日、整備） | 長尺。来歴の記録 |
| 5 | 正直な話 | 大変だったことは？ それでも乗り続ける理由は？ | 長尺。信頼の源 |
| 6 | 継承 | いつか手放すとしたら、どんな人に乗ってほしいですか？ | 長尺。継承の物語 |
| 7 | 若い世代へ | 20代の自分に、この車のことを何と伝えますか？ | ショート③（最重要） |
| 8 | 締め | エンジンをかけて、少し走る（会話なし） | ショート④。音と景色 |

**聞き方のコツ**
- 「成功の秘訣は？」とは聞かない。成功は、言葉の選び方と佇まいから視聴者が感じ取る。
- 5（正直な話）は必ず入れる。故障や手間の話がある方が、憧れが嘘にならない。
- 答えが長くても止めない。編集で削る。

## 3. 編集の型

### ショート（縦 9:16、30〜60秒）
- **冒頭2秒**：車と本人のカット＋その回の一番強い一言をテロップで。
- 本編：1つの質問に1つの答え。BGMは控えめ（エンジン音を主役に）。
- 最後：「フル版はYouTubeで」と、フル版へ誘導する一言を入れる。
- タイトルの例：「建築家が、新車ではなくXJを選んだ理由」「20代の自分に伝えたいこと｜XJSオーナー」

### 長尺（横 16:9、5〜10分）
- 構成は2章の順番どおり。チャプターを付ける。
- 説明欄：車種・年式、撮影場所（地域まで）、整備記録へのリンク（アーカイブページ）、PR表記が必要な場合はその旨。
- 最後に、コメント欄への問いかけを入れる（下記）。

### コメント欄への問いかけ（動画の最後に一言）
- 「オーナーの方、あなたのJaguarの年式と、一番好きな瞬間をコメントで教えてください」
- 「これからJaguarに乗りたい方、一番不安なことを書いてください。すべてお答えします」

## 4. 公開後のコメント運営

| タイミング | やること |
|---|---|
| 公開直後 | 出演者本人に一言コメントしてもらい、固定する。本人名義が難しければ、店が「○○様より」と代筆して固定 |
| 24時間以内 | すべてのコメントに店のアカウントで返信する |
| 悩みのコメント | 整備の知見で丁寧に答える。「詳しくはLINEで」と誘導しすぎない（まずは公開の場で答える） |
| 否定的なコメント | 事実の誤りだけを丁寧に正す。言い争わない。攻撃的なものは非表示にする |
| 1週間後 | 良いコメントを選び、本人の許可を取ってアーカイブページへ転載する |

**固定コメントの文例（出演者本人）**
> 撮影ありがとうございました。この車と暮らして○年になります。うまく話せませんでしたが、いい車です。見かけたら声をかけてください。

**固定コメントの文例（店の代筆）**
> 【○○様より】撮影ではありがとうございました。○年、大切に乗ってきました。この車のことを分かってくれる人に、いつか繋げたいと思っています。

**YouTube Studioの設定**：「不適切な可能性があるコメントを保留して確認する」をオン。リンクを含むコメントとNGワードは保留にする。

## 5. 映像・肖像の利用許諾書（ひな形）

> ※ ひな形です。正式に使う前に、専門家（弁護士など）の確認を受けてください。

```
映像・肖像等の利用に関する同意書

エムガレージ（以下「当店」）は、下記の撮影で得た映像・写真・音声・発言（以下「本素材」）を、
下記の範囲で利用することについて、出演者の同意を得るものとします。

1. 撮影日・場所：
2. 対象車両：車種／年式／車台番号（下4桁）
3. 出演の形：□顔出し □後ろ姿・手元のみ □声のみ □テロップのみ
4. 表示する肩書き：（例：建築設計）　□氏名を表示しない □名のみ □氏名
5. 利用する媒体：□YouTube □Instagram □TikTok □当店ウェブサイト □店頭・イベントでの上映 □印刷物
6. 利用する期間：□期間を定めない □公開から○年
7. 対象車両を将来売却・委託販売する場合の利用：
   □当該車両の販売ページ・販売時の資料に、来歴として本素材を利用してよい
   □利用しない
8. 編集：当店は本素材を、趣旨を変えない範囲で編集（短縮・切り出し・字幕付け）できます。
9. 写り込み：ナンバー、自宅・勤務先が特定できる情報は、当店の責任でぼかし等の処理をします。
10. 取り下げ：出演者は、公開後いつでも当店に申し出て、当店の管理する媒体からの削除を求めることができます。
    （ただし、第三者による転載や、削除前に保存されたものについては、当店は責任を負いかねます）
11. 対価：□なし □あり（内容：　　　　　）
12. 個人情報：当店は出演者の個人情報を、本撮影と連絡以外の目的に使いません。

上記に同意します。
　　年　　月　　日　　出演者署名：　　　　　　　　　　当店：
```

**7番が最も重要。** これがないと、その車を販売する時に動画を来歴として使えない。

## 6. 公開までのチェックリスト

- [ ] 許諾書の署名がある（顔出しの範囲、7番の選択を確認）
- [ ] ナンバー、住所、勤務先がぼかされている
- [ ] 「成功の誇示」に見える編集になっていないか（トーンの指針 S-7 を確認）
- [ ] 正直な話（大変だったこと）が長尺に入っている
- [ ] 説明欄に車種・年式とアーカイブページへのリンクがある
- [ ] 出演者に公開日を伝え、固定コメントを依頼した
- [ ] 公開後、アーカイブ（Owners Archive）の該当車両に動画を紐付けた
