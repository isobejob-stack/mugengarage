## 3. 台本：シリーズA「最後の本物のJaguar」

**トーンの原則**：新しいJaguarを悪く言わない。「失われたもの」ではなく「今も走り続けているもの」として語る。

### A-1「最後の直列6気筒」（ショート45秒／長尺は同じ構成を8分に）

| 秒 | 画 | 言葉（テロップ／ナレーション） |
|---|---|---|
| 0〜3 | X300の正面、エンジン始動 | 「Jaguar最後の、直列6気筒。」 |
| 3〜12 | エンジンルーム、AJ16の刻印 | 1994年、X300型XJとともに登場したAJ16エンジン。3.2リッターで216馬力、4.0リッターで246馬力。 |
| 12〜22 | 走行シーン | XKエンジンから続いた、Jaguarの直列6気筒の系譜。その最後の世代がこのエンジンです。 |
| 22〜32 | 室内、ウッドパネル | 1997年、XJのエンジンはV8に一本化されます。この形のJaguarが作られたのは、3年あまりでした。 |
| 32〜42 | 店のガレージ、整備風景 | （店の見立て）距離を走った個体でも、エンジンの腰下がしっかりしていることが多い。長く乗る前提なら、有力な世代です。 |

出典：図鑑「AJ16エンジン」「X300型 XJ」（裏取り済み）。42秒の見立ては CONTENT_FACTCHECK.md で店主の確認待ち。

## 4. シリーズC「Jaguarあるある図鑑」10項目（案）

**ルール**：笑いは「自分たちを笑う」まで。他の車や他のオーナーを笑わない。最後は必ず「こう付き合う」（店の知見）で締める。**「こう付き合う」は店主の確認を経てから公開する。**

| # | あるある（ショートの冒頭の一言） | こう付き合う（店の答えの方向性） |
|---|---|---|
| C-1 | 「ジャガーに乗ってる」と言うと、必ず「壊れない？」と聞かれる | 壊れる前に替える部品は、だいたい決まっている（予防整備の話へ） |
| C-2 | 乗る前に、つい暖機の時間を楽しんでしまう | 暖機の考え方（サイトの「ジャガーを知る」4章の内容と揃える） |
| C-3 | 夏の渋滞で、水温計を見る回数が増える | 冷却系は先手で替える（同上） |
| C-4 | ウッドパネルを、乗るたびになでてしまう | ウッドとレザーの手入れの仕方（店で記入） |
| C-5 | 駐車場では、なぜか一番端に停める | ドアの開け閉め、ボディの守り方 |
| C-6 | 知らない人から「昔乗ってました」と話しかけられる | オーナーが語りたくなる瞬間（サークルへの誘導） |
| C-7 | 家族に「もう1台いるでしょ」と言われる | 本当に2台目が必要かどうか。予防整備で“突然”を減らす |
| C-8 | 警告灯が点いたら、まず店にLINEする | 慌てなくていい警告と、すぐ止めるべき警告（店で記入） |
| C-9 | 給油のたびに、燃費の話はしないことにしている | 実際の燃費の目安（店の実測値で記入） |
| C-10 | ボンネットのリーピングキャットを、子どもに触られる | 歴代のマスコットの小話（図鑑の範囲で） |
