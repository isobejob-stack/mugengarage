# S-4 オーナーズサークル立ち上げキット

> **2026-10-31 改訂：撤回（忙しいオーナーには集まりのメリットが薄く、少人数の運営には負担が大きいため）。** 詳細は `docs/strategy/07_revision_small_team.md`。

> 目的：オーナーの「孤独」と「誇りを表現する場のなさ」（イシューツリー B2・B3）を解消し、継続と紹介を生む“部室”を作る。
> 原則：**小さく始めて、続ける。** 最初は費用ゼロ（LINE）、月1回の朝の集まりから。
> 参考：H.O.G.（購入で自動入会、販売店が地域の拠点）、マツダ ロードスター軽井沢（初参加者が約4割）。

## 1. 場の設計

| 項目 | 設計 |
|---|---|
| 名前（仮） | エムガレージ オーナーズサークル |
| 入れる人 | エムガレージで購入した人、整備を任せている人（＝自動で招待）。**Jaguarを持っていない検討中の人は「見学枠」**として朝の集まりにだけ招く |
| 器 | **LINEオープンチャット（参加承認制・参加コードあり）**。ニックネームで参加でき、個人のLINEアカウントが他の参加者に知られない |
| 店の役割 | 管理人。話題を振る、質問に答える、荒れたら止める。**宣伝の場にはしない**（在庫の告知は月1回まで） |
| 既存の公式LINEとの関係 | 公式LINE＝店と1対1の相談窓口（今まで通り）。オープンチャット＝オーナー同士の場 |
| 会費 | 無料。将来、有料メンバーシップ（優先整備枠、イベント）を検討する時の土台にする |

## 2. ルール（オープンチャットの「ノート」に固定）

```
エムガレージ オーナーズサークルへようこそ

ここは、Jaguarと暮らすオーナー同士が、気軽に話せる場所です。

1. 自分の車の写真、出かけた話、困りごとを、自由に書いてください。
2. 質問には、店のスタッフもお答えします。故障の相談も歓迎です。
3. 他の方の車や選択を否定しないでください。年式も仕様も、いろいろあって良いのです。
4. 売買・宣伝・勧誘の投稿はご遠慮ください（車を手放す時は、まず店にご相談ください）。
5. ナンバーや住所が写った写真は、ぼかしてから投稿してください。
6. 政治・宗教など、車と関係のない議論はしないでください。

ルールに反する投稿は、管理人が削除することがあります。
```

## 3. 案内文

### 既存のお客様への招待（公式LINEで送る）

> いつもありがとうございます。エムガレージです。
> このたび、Jaguarオーナーの皆さまが気軽に話せる「オーナーズサークル」をLINEオープンチャットで始めました。
> ニックネームで参加でき、ほかの参加者にご自身のLINEアカウントが知られることはありません。
> 愛車の写真、ドライブの話、ちょっとした困りごとなど、自由にお使いください。
> 月に一度、日曜の朝に、景色の良い場所でコーヒーを飲む集まりも始めます。
> 参加はこちらから：（リンク）　参加コード：（コード）

### 納車時に渡すカード（印刷して車検証入れに）

> ようこそ、Jaguarのある暮らしへ。
> 困った時は、まず公式LINEへ。仲間と話したい時は、オーナーズサークルへ。
> （QRコード2つ：公式LINE／オーナーズサークル）

## 4. 最初の1ヶ月の運営

| 週 | 店がやること |
|---|---|
| 1週目 | 店長があいさつと自己紹介（店の歴史、自分の最初のJaguar）。「愛車の写真を1枚どうぞ」と呼びかける |
| 2週目 | 「あなたのJaguarの名前（愛称）は？」などの答えやすいお題を出す |
| 3週目 | 整備の小ネタ（例：夏前に冷却系で見ておくこと）を、写真つきで投稿 |
| 4週目 | 朝の集まりの告知。参加表明を募る |

**やってはいけないこと**：在庫の宣伝を続けて流す／質問を放置する／常連だけの内輪の会話にする（新しい人には必ず店から声をかける）。

## 5. 第1回 朝の集まり 企画書

| 項目 | 内容 |
|---|---|
| 名前（仮） | Sunday Morning Jaguar（日曜の朝のジャガー） |
| 日時 | 日曜 7:00〜9:00（交通量が少なく、近隣に迷惑をかけにくい） |
| 場所の条件 | ①景色が良い ②駐車場の利用について、施設に事前に許可を取れる ③トイレがある ④コーヒーが買える（カフェ併設が理想）。**店のガレージは「部室」として使ってもよい** |
| 規模 | 最初は5〜10台。見学枠（車なし、検討中の人）も受け付ける |
| 内容 | 自由に車を見て話すだけ。店長が初参加の人を紹介する。最後に全員で1枚写真を撮る |
| 店の準備 | 名札（ニックネームと車種）、簡単な飲み物、整備の相談コーナー（その場で軽く見る） |
| 発信 | 参加者の許可を取って、写真をInstagramとオーナーズサークルに投稿。ナンバーはぼかす |

**守ること（近隣と安全）**
- 空ぶかし、急発進、長いアイドリングはしない。
- 施設の駐車ルールに従い、通常の利用客の邪魔をしない。
- 解散は流れ解散。集団で走り出さない。
- 雨天は中止（判断は前日18時にサークルで告知）。

**毎回記録すること（KPI）**：参加台数、**初参加者の数**、見学枠の人数、その後のLINE相談の件数。
目標：初参加者の比率 30〜40%（軽井沢ロードスターミーティングは約41%）。

## 6. 3ヶ月後に見直すこと

- 書き込みの多い人、少ない人の偏り。新しい人が話せているか。
- 朝の集まりの参加台数と初参加者の推移。
- 店への相談（整備・購入・紹介）がサークル経由で生まれたか。
- 次の一手：Grand Tour（年1回の旅、`06_strategy.md` C5）の企画を始めるか。
