# S-7 トーン＆マナーの指針

> 目的：誰が書いても、誰が撮っても、エムガレージの世界観（英国、クラシック、重厚感、上質）と信頼が崩れないようにする。
> 使い方：投稿・動画・ページを公開する前に、5章のチェックリストで見直す。

## 1. 私たちの声

| こうありたい | こうはならない |
|---|---|
| 落ち着いていて、知識がある | 偉そう、専門用語で煙に巻く |
| 正直（弱点も先に言う） | 都合の悪いことを隠す |
| 美意識がある | 気取っている、成金趣味 |
| 自分たちを笑えるユーモア | 他の車や他人を笑う |
| オーナーが主役 | 店が主役 |

## 2. 言葉づかい

- **成功を誇示する言葉を使わない。** 「勝ち組」「ステータス」「成功者の証」「富裕層」は使わない。見せるのは、手間を惜しまない生き方と美意識（インサイト I-5）。
- **値上がりを煽らない。** 「今が買い時」「資産になる」「値上がり確実」は使わない（投機化は若い世代を締め出す）。
- **新しいJaguarを批判しない。** 「今のJaguarは本物じゃない」とは言わない。「この形のJaguarは、もう新しくは作られない」と事実で語る。
- **「壊れない」と言わない。** 代わりに「壊れる前に替える部品は決まっている」「直し続けます」と言う。
- 数字には出典を付ける。店の見立ては「私たちの経験では」と書く。
- カタカナ語より、分かりやすい日本語を優先する（例：「メンテナンス」より「整備」でよい場面は「整備」）。

## 3. 写真・映像

- 車は「道具」ではなく「暮らしの一部」として撮る（駐車場の真ん中より、木漏れ日の道、職場の前、朝の光）。
- 人を撮る時は、顔よりも手元、後ろ姿、佇まい。出演の範囲は本人が決める（S-2）。
- ナンバー、住所、勤務先は必ずぼかす。
- 誇張した加工（彩度を上げすぎる、高級品を並べる演出）をしない。

## 4. やらないこと

- 一般のファンを装った投稿、口コミ、コメント（ステマ規制。景品表示法、2023年10月施行）。
- 依頼した投稿に、PR表記を付けないこと。
- 他店の悪口。他店の在庫や価格への言及。
- 出演者や参加者の許可のない写真の公開。
- 炎上を狙った過激な表現。

## 5. 公開前のチェックリスト

- [ ] 主役はオーナーか、車の物語か（店の自慢になっていないか）
- [ ] 成功や富を誇示する表現になっていないか
- [ ] 値上がりや投資をにおわせていないか
- [ ] 新しいJaguarや他の車を悪く言っていないか
- [ ] 弱点（手間、費用）にも触れているか
- [ ] 数字に出典があるか。店の見立ては見立てと分かるか
- [ ] ナンバー、住所、勤務先はぼかしたか
- [ ] 依頼・提供した投稿にPR表記があるか

## 6. 否定的な反応・炎上の時

| 状況 | 対応 |
|---|---|
| 事実の誤りの指摘 | 確認して、誤りなら24時間以内に訂正し、訂正したことを明記する |
| 「ジャガーは壊れる」などの否定的なコメント | 否定しない。「よく言われます。だから私たちは…」と、予防整備や伴走の話につなげる |
| 店への不満（実際のお客様） | 公開の場で言い争わない。「詳しくお話を伺えますか」と、公式LINEか電話に移す |
| 攻撃的・差別的なコメント | 非表示にする。反応しない |
| 出演者への誹謗中傷 | すぐ非表示にし、出演者に連絡する。必要なら動画を非公開にする |
| 大きな炎上 | 投稿を止め、店主が事実関係を確認してから、一度だけ公式に説明する |
