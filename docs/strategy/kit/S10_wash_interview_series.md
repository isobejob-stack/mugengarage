# S-10 「洗車×オーナーズインタビュー」企画書

> 位置づけ：3人体制での中核施策（`docs/strategy/07_revision_small_team.md`）。
> 一言で：**徹底洗車を入口に、車好き向けの動画と成功者インタビューを1本にし、洗車のたびにオーナーと会う関係をつくる。**

## 1. 役割分担

| 人 | 担当 | この企画での仕事 |
|---|---|---|
| 本人 | 戦略 | 出演候補の選定と案内、価格と特典の設計、記録（CRM）と次回案内、数字の振り返り |
| 兄 | バズ企画・動画編集 | 企画とタイトル、撮影、編集（長尺1本＋ショート3〜4本）、公開とコメント返信 |
| 父 | 車とオーナーの応対 | オーナーの迎え入れと受け渡し、洗車の監修、**洗いながらの点検と所見**、インタビューの聞き手 |

**父が聞き手になるのが大事。** 成功者は、若い聞き手よりも、車を分かっている同世代の専門家の方が本音を話しやすい。

## 2. 1台の流れ（所要：半日〜1日）

| 段取り | 内容 | 担当 |
|---|---|---|
| 予約 | 公式LINEで日程を決める。出演の有無と、同意書（S-2の5章）を事前に送る | 本人 |
| 受け取り | 来店、または引き取り（忙しい人向け。範囲と料金は要検討） | 父 |
| ビフォー撮影 | 汚れた状態を全方位で撮る。オーナーがいれば一言もらう | 兄 |
| 洗車 | 外装、ホイール、室内、エンジンルーム（範囲は3章） | 父・兄 |
| 点検と所見 | 洗いながら気づいた点を記録（オイル漏れ、ゴムの劣化、錆、電装） | 父 |
| インタビュー | 受け渡しのときに30分。仕上がった車の前で | 父（聞き手）・兄（撮影） |
| アフター撮影 | 仕上がりの全方位、ディテール（ウッド、レザー、エンブレム）、走り出し | 兄 |
| 受け渡し | 仕上がりの確認と、所見の報告（写真つき） | 父 |
| 記録 | 車の状態、所見、話したこと、**次に乗ってみたい車**をCRMに残す | 本人 |

## 3. 洗車メニューと価格（案。最終決定は店）

| 項目 | 案 | 決めること |
|---|---|---|
| 基本：徹底洗車 | 3万円（外装の手洗い、ホイール、室内清掃、ウッドとレザーの手入れ、エンジンルームの簡易清掃） | 範囲と時間。近隣のディテイリング店の料金表を3〜5件見て、高すぎず安すぎない位置に置く |
| 出演特典 | 本人の案：5,000円引き | 下の比較を見て決める |
| 2回目以降 | 出演済みのオーナーは優先予約。季節ごと（年3〜4回）の案内 | 定期の割引を作るか |

**旧車ならではの注意**：古い車の塗装は、現代の車より薄かったり、クリア層がなかったりすることがある。研磨（磨き）を入れるかどうかは、父が個体ごとに判断する。**基本メニューには研磨を入れない**のが安全。

### 出演特典：値引きか、追加作業か

| | 5,000円引き（本人の案） | 追加作業で返す（例：レザーの保湿、エンジンルームの徹底清掃） |
|---|---|---|
| 分かりやすさ | ◎ 一目で分かる | ○ 説明が要る |
| 価格の印象 | 「3万円は定価ではない」と受け取られる余地がある | 3万円の価値が下がらない |
| ハイクラス層への響き | 5,000円は動機になりにくい | 「特別扱い」として響きやすい |
| 店の負担 | 現金の減収 | 作業時間が増える |

**おすすめは「追加作業」**。どちらにしても、出演はあくまで任意にする（出演しない洗車だけの客も大歓迎、という姿勢を崩さない）。

## 4. 動画の構成（兄の担当。2段構造）

**1本目の形（長尺 12〜20分）**

| 順 | パート | 見る人 | 狙い |
|---|---|---|---|
| 1 | フック（10秒）：汚れた状態＋オーナーの一番強い一言 | 全員 | 離脱を防ぐ |
| 2 | 車の紹介：年式、車種、この個体の来歴（父の解説） | 車好き | 専門店の目 |
| 3 | 洗車の工程：泡、水、ブラシ、作業の音。汚れが落ちる瞬間 | 車好き・洗車好き | 気持ちよさ（バズの核） |
| 4 | 父の所見：「この年式はここが傷みやすい。この車は…」 | 車好き・検討者 | 信頼と知識 |
| 5 | インタビュー：仕事で大事にしてきたこと、なぜこの車か、20代の自分へ、次に乗りたい車 | 一般層・若い層 | 憧れと人の物語 |
| 6 | ビフォーアフターと納車：オーナーの反応 | 全員 | 満足感とコメント |

**ショート（各30〜60秒、1台から3〜4本）**
- ビフォーアフターの対比（最も伸びやすい型）
- 作業の気持ちいい1カット（泡、汚れの流れ落ち、レザーの手入れ）
- オーナーの一言（「20代の自分に伝えたいこと」）
- 父の「この車のここを見てほしい」

**タイトルの型（例）**
- 「[職業]が[年数]年乗り続ける[年式][車種]を、徹底洗車してみた」
- 「[車種]を[年数]年ぶりに本気で洗ったら…」
- 「この車を選んだ理由を聞いたら、人生の話になった」

**成功者らしさの出し方**：職業はテロップで一行だけ。成功を語らせない。仕上がった車の前で話す姿と、言葉の選び方で伝える（S-7 トーン＆マナー）。

## 5. 営業につなげる仕組み（接触回数を増やす）

| 仕組み | やり方 |
|---|---|
| 次の洗車の案内 | 3〜4ヶ月後にCRMのリマインダー（FR-CRM-004）を設定し、公式LINEで案内する |
| 所見の報告 | 受け渡しの時に写真つきで伝え、次回までに直すべき箇所の見積もりを添える |
| 乗り換え・入荷の連絡 | インタビューで「次に乗ってみたい車」を必ず聞き、CRMに残す。**合う車が入った時だけ**個別に連絡する（一斉送信の営業はしない） |
| 買取・委託 | 「いつか手放す時は」の話を、インタビューの質問（S-2の6番）で自然に聞いておく |
| 紹介 | 動画を見た知人からの問い合わせを、出演者に報告する（出演者の誇りになる） |

**数字で見るもの（月次）**：洗車の件数、うち出演の件数、リピート率、洗車から生まれた整備の受注、乗り換え・買取の相談件数、コアオーナー1人あたりの年間の接触回数。
**動画で見るもの**：ショートの再生数と保存数、長尺の視聴維持率、登録者数、「動画を見て」という問い合わせの数。

## 6. 量の目安（3人で無理なく回る量）

- **月2台から始める**（長尺2本＋ショート6〜8本／月）。
- 最初の10本は実験と考える。タイトル、サムネイル、尺、構成を1本ごとに1つずつ変えて、伸びた型を残す。
- **パイロットは在庫車で撮る**のがおすすめ。出演者がいなくても撮れて、洗車動画がそのまま在庫車の紹介にもなる。

## 7. リスクと対策

| リスク | 対策 |
|---|---|
| 預かり中の事故・損傷 | **預かった車の事故に備える保険（受託自動車に関する賠償責任の補償）に入っているか確認**。作業前に傷の有無を写真で記録し、オーナーと共有する |
| 旧車の塗装を傷める | 基本メニューに研磨を入れない。薬剤は目立たない場所で試す。判断は父 |
| 個人情報の写り込み | ナンバー、自宅、勤務先はぼかす。同意書（S-2の5章）を流用 |
| ステマ規制 | 店のチャンネルで店のサービスを見せるのは問題ない。**出演者が自分のSNSで紹介する場合、特典を受けているならPR表記を付けてもらう** |
| 伸びない時期 | 最初の10本は型を探す期間と割り切る。ショートで反応を見て、長尺の題材を選ぶ |
| 父の負担 | インタビューは受け渡しの30分に収める。編集は兄、記録と案内は本人で分ける |

## 8. 最初の一歩（今週）

1. **洗車メニューの範囲と価格を決める**（近隣のディテイリング店の料金表を3〜5件見る）。
2. **保険を確認する**（預かった車の事故への補償）。
3. **パイロットを1本撮る**。在庫車で、兄が撮影と編集の型を試す。
4. **最初の出演者を3名選ぶ**。父のお得意様から、話してくれそうな方。
5. **出演特典を決める**（値引きか、追加作業か）。
6. 対象を **Jaguarと英国車に絞るか、ハイクラスの旧車全般に開くか** を決める。
   - 絞る：専門店としての一貫性が保てる
   - 開く：ハイクラスのオーナーとの接点が増え、乗り換え・買取の入口が広がる（月1本までなど、比率を決めて開く手もある）
