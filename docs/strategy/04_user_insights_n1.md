## 4-2. 声から抽出したインサイト

**I-1. 人は「スペック」ではなく「一目惚れ」で買い、「伴走」の有無で残るか去るかが決まる。**
V1〜V4は全員がデザインへの一目惚れや「人の勧め」から入っている。V5は伴走がなく離脱し、V8は良い体験があったから乗り継いだ。
→ **獲得は「見せる」（路上・映像・イベント）、継続は「伴走」（整備・相談・仲間）。** 両者は別の仕事。

**I-2. 「壊れる」は不安の正体ではない。「いくらかかるか分からない」「誰に相談すればいいか分からない」が正体。**
V6とV7が示すように、維持費の不満と車への愛着は両立する。V7の「劣化の連鎖」は、予防整備で予測可能になる。
→ **不確実性をなくす**ことが最大の購買促進策。年間の維持費を見える化し、予防整備の計画と相談窓口を用意する。

**I-3. 若い買い手は「比較しない」。だから「出会い」の設計がすべて。**
V1は他の車を知らずに選んでいる。V2はスポーツカー検討中に「出会って」乗り換えた。
→ 若年層は検索比較型ではなく**遭遇型**。ショート動画、街中、友人、イベントでの遭遇を増やす。

**I-4. 継承と家族の記憶は、価格を超える動機になる。**
V9とV12。ユーザーの「来歴（いい人が乗っていた車を継ぐ）」という仮説と一致する。
→ オーナーズインタビュー、アーカイブ、レジストリは「感傷」ではなく**価格を支える情報資産**。

**I-5. 「成功者の印象」は“お金”ではなく“手をかける余裕と美意識”から生まれる。**
V11。ユーザーの「成功者の印象をつける」という仮説は正しいが、見せ方を誤ると「見栄」に見える。
→ 発信のトーンは「成功の誇示」ではなく「**美意識と手間を惜しまない生き方**」。

## 4-5. 提言：自社でN1インタビューを回す（最重要）

外部の声は断片にとどまる。**M-GARAGEには30年分の顧客という、他社が持てない一次情報源がある**。オーナーズインタビュー動画の撮影と同時に、以下の構造化インタビューを行い、記録を蓄積する。

**対象（各3〜5名、計15〜20名）**：P2（乗り換え組）、P3（帰ってきた愛好家）、P4（長期オーナー）、**手放した元オーナー**（離脱理由）、**問い合わせたが買わなかった人**（障壁）。

**質問ガイド**
1. 初めてJaguarを意識した瞬間は？（いつ、どこで、誰と）
2. 買う前に一番怖かったことは？　それはどう解消した？（しなかった？）
3. 他に検討した車は？　なぜJaguarに決めた？
4. 所有して「想像と違った」ことは？（良い意味でも悪い意味でも）
5. 家族や友人の反応は？
6. この車のことを、誰かに話したくなるのはどんな時？
7. 手放すとしたら、どんな人に乗ってほしい？
8. 20代の自分に、この車のことを何と伝える？

**記録の仕方**：発言を「動機／不安／転機／誇り／離脱」のタグで分類し、CRMの顧客タイムライン（FR-CRM-002）にメモとして残す。**この蓄積が、コンテンツの企画、在庫の仕入れ判断、価格設定の根拠になる。**
