# Step 5 — 分析と統合：何が本質的な課題で、どこに勝ち筋があるか

> Step 1（市場構造）、Step 2（Jaguarの現在地）、Step 3（他業界の型）、Step 4（N1の声）を統合し、戦略を立てる前提となる「論点」と「勝ち筋」を絞り込む。

## 5-1. 課題の構造化（イシューツリー）

**メインの問い：なぜ日本のクラシックJaguarの界隈は、ミニやロードスターのように盛り上がっていないのか？**

```
なぜ盛り上がらないか
├─ A. 需要：新しい人が入ってこない
│   ├─ A1 若い世代との接点がない（遭遇がない）……………… Step1: Z世代の入口はYouTube/Instagram
│   ├─ A2 「おじさんの車」「壊れる」という印象 ……………… Step4: V5, V7
│   └─ A3 維持費と相談先が分からない（不確実性）…………… Step4: I-2
├─ B. 継続：入った人が残らない・語らない
│   ├─ B1 購入後1年目の“想定外”で離脱 …………………………… Step4: V5
│   ├─ B2 集まる場と仲間がいない（孤独）……………………… Step2: 2-4 クラブの可視性が低い
│   └─ B3 誇りを表現する場がない ………………………………… Step3: H.O.G., Luftgekühlt
├─ C. 継承：良い個体が次に繋がらない
│   ├─ C1 来歴が記録されていない → 価値が正当に評価されない … Step2: 記録のある車が値を保つ
│   └─ C2 安い個体が“整備の負債”を抱えたまま流通する ……… Step2: 2-2
└─ D. 構造：個店では動かせない壁
    ├─ D1 旧車重課の税制、協定価額が市場価値と乖離した保険 … Step1: 1-3
    ├─ D2 整備士の高齢化と不足 …………………………………… Step1: 1-3
    └─ D3 ヘリテージの担い手の空席（メーカーは未来へ）………… Step2: 2-1
```

**示唆**：A〜Cは**一店舗でも動かせる**。Dは**連合（業界）で動かす**必要がある。戦略も「事業」「コミュニティ」「業界」の3層に分けて設計する。

## 5-2. 中心的な発見：「意味」と「価格」の大きなギャップ

| | 意味（文化的価値） | 価格（市場価値） |
|---|---|---|
| Eタイプ | 世界的なアイコン（極めて高い） | 高い（コンティニュエーションは£28.5万〜） |
| XJ（X300など）、XJS | 「英国の本物」「Jaguarらしさの最後の世代」（高い） | **100〜250万円＝新型の軽自動車並み**（低い） |

- XJやXJSは、**意味の割に価格が低すぎる**＝「過小評価された本物」。Radwoodが1980〜90年代車で、空冷ポルシェ文化がLuftgekühltで示したように、**文化として語られると評価は後からついてくる**。
- ただし、狙うべきは**投機的な値上がりではない**（Z1/Z2のように若者を締め出す）。狙うのは**市場の二層化**である。
  - **記録のある個体**（来歴、整備記録、オーナーの声が揃う）→ 正当なプレミアム
  - **記録のない個体** → 現状の価格
- この二層化の「記録」を作れるのは、**整備を担い、オーナーと関係を持つ専門店だけ**。ここがM-GARAGEの構造的な勝ち筋。

## 5-4. 戦略上の4つの論点と結論

| 論点 | 選択肢 | 結論 | 理由 |
|---|---|---|---|
| **Q1 誰を主役にするか** | 既存の40〜70代／乗り換え組／若手 | **「主役」は現オーナー（P4）、「育てる市場」は乗り換え組（P2）と若手（P1）** | 熱源は現オーナーの語り。P2は今の売上、P1は5〜10年後の市場 |
| **Q2 どこで戦うか** | Jaguar単独／英国クラシック全体 | **二層構造。自社の深さはJaguar、界隈の広さは英国クラシック全体** | 母数の小ささを連合で補う（ジャパンミニデイ型）。専門性は薄めない |
| **Q3 何で勝つか** | 価格／在庫数／専門性／来歴と伴走 | **「来歴（Provenance）×伴走（Partnership）」** | 価格と在庫では大手中古車店に勝てない。来歴と伴走は時間をかけた関係でしか作れず、模倣されにくい |
| **Q4 当事者と第三者をどう使い分けるか** | すべて自社名で／すべて匿名で | **当事者＝M-GARAGEの名前で本業と伴走を担う。第三者的＝運営者を明示した“界隈の公共財”（レジストリ、相場、連合イベント）を担う** | ステマ規制（2023年10月施行。事業者の表示であることが判別困難な場合に違法）を守りつつ、界隈全体の信頼を得る |

## 5-5. 戦略の仮説（Step 6で具体化）

> **「クラシックJaguarの“記録者であり伴走者”になり、オーナーが語り、次の世代が継ぐ循環を作る。」**

- 来歴の記録 → 価値の可視化 → オーナーの誇り → 語り（コンテンツ） → 新しい人との遭遇 → 安心して入れる入口 → 伴走 → 記録……
- この循環（フライホイール）が回るほど、**M-GARAGEは「Jaguarを買う店」から「Jaguarの歴史が集まる場所」になる**。
