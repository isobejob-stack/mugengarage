# Step 1 — 市場構造の整理（世界／日本）

> 目的：クラシックカー（特にクラシックJaguar）の市場が「どこでお金と熱が動いているか」を構造的に把握する。
> 調査日：2026-10-30。数字は出典ごとに定義が違うため、必ず出典とセットで扱う。

## 1-1. 世界市場：規模と流れ

| 指標 | 数字 | 出典・注記 |
|---|---|---|
| オークション＋オンライン取引額（2025） | 約48億ドル（前年比 +10%） | Hagerty（CNBC 2025-12-19） |
| うちオンライン | 約25億ドル（+12%）＝**全体の過半** | 同上 |
| Bring a Trailer 単体の取引額（2025） | 約17.1億ドル／49,486件／落札率81%／登録ユーザー+25.5万人 | BaT発表（The Shop, CarPro） |
| BaT 取引額推移 | 2023: 約14億 → 2024: 約15億 → 2025: 約17億ドル | CNBC, Jalopnik, The Shop |
| 「市場規模」推計 | 386〜408億ドル（2025） | 調査会社推計。方法論不明のため参考値扱い |
| Hagerty Collector Car Market Rating | 2026年1月 58.28（約15年ぶり低水準）→ 59.01 | 「フラット市場」 |
| Hagerty Hundred（保険対象の一般的旧車の価値指数） | 2022年ピーク後、緩やかに下落 | Motorious |

**読み解き**
1. **取引の主戦場はオンラインに移った。** オークション会場（年配の富裕層）→ オンライン（コメント欄で集合知が働く場）。BaTは「売買サイト」ではなく「コメント欄というコミュニティ」が価値の源泉（後述 Step 3）。
2. **トップエンドは強いが、中間層の“普通の旧車”は軟化。** 1960〜70年代の大衆的クラシックは冷え、1990年代以降の「アナログ最後の世代」が上がる。＝**世代交代（ジェネレーショナル・ハンドオフ）** が起きている。
3. **価格の牽引役が「投資」から「体験・文化」へ。** 指数はフラット、しかし取引件数とユーザー数は増加。「値上がり期待で買う人」から「乗りたい・語りたい人」へ主役が移る局面。

**読み解き**：若い世代は「高い名車」ではなく「**手が届く本物**」から入る（2000年代のカローラ、初代ロードスター等）。入口は**YouTubeとInstagram**。

## 1-3. 日本市場の構造的特徴

| 論点 | 事実 | 戦略的含意 |
|---|---|---|
| **旧車に重い税制** | 自動車税：初度登録13年超で約15%重課（ディーゼル11年超）。重量税：13年超・18年超の2段階で重課。HV/EVは対象外 | 「維持費が高い」という不安の一部は**制度起因**。不安を数字で透明化すれば解ける。業界として声を上げる余地（ベストカー等が反対論陣） |
| **車齢の長期化** | 乗用車の平均車齢 9.44年（2025年3月末、31年連続で過去最高）、平均使用年数 13.35年 | 「古い車に長く乗る」こと自体は社会の流れと一致。サステナビリティの物語に乗せられる |
| **国産旧車の海外流出** | 米国25年ルールで右ハンドル旧車の輸入が可能になり、国産スポーツが流出・価格高騰 | 国産旧車は「投機」色が強まり、若者には手が届かなくなった。**輸入クラシック（英国車）は相対的に割安な“空白地帯”** |
| **整備士不足・高齢化** | 若者の整備士志望減、整備要員の平均年齢上昇、整備業者の倒産増（国交省・ベストカー） | 旧車の最大のボトルネックは「車」ではなく「**直せる人**」。専門店の技術そのものが希少資源 |
| **ワンメイク・ミーティングの成功例** | ジャパンミニデイ in 浜名湖：約3,000台（過去最多）、主催はミニ専門店の団体JMSA | 日本では「専門店の連合」が界隈の祭りを作れることが実証済み |

## 1-4. 価値連鎖（バリューチェーン）で見る市場マップ

```
[供給]            [流通]                [所有の支援]            [文化・意味づけ]
個体（現存車）  → 専門店／一般中古車店 → 整備・レストア       → メディア（YouTube/雑誌）
部品（純正・    → オークション         → 保険（日本は協定価額   → イベント・ミーティング
  リプロ）      → 個人売買             →   型が弱い）           → オーナーズクラブ
技術（整備士）  → 海外輸出入           → 保管・税・車検        → 来歴・記録（レジストリ）
```

- **お金が落ちるのは左側（販売・整備）だが、需要を生むのは右側（文化）。** 右側が痩せると、左側は値下げ競争になる。
- 海外ではHagertyが「保険×メディア×クラブ×相場データ×マーケット」で右側を統合し、左側の需要を作っている（Step 3）。**日本にはこのポジションの担い手がいない。**
- クラシックJaguarでは、右側（文化）が**ほぼ空白**。ここが本戦略の主戦場。
