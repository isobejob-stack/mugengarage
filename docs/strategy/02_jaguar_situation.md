# Step 2 — クラシックJaguarの現在地

> 目的：Step 1の市場構造の中で、クラシックJaguarがどこに立っているかを特定する。

## 2-1. メーカー（JLR／Jaguar）の動き：「新しいJaguar」と「古いJaguar」の分断

| 時期 | 出来事 | 出典 |
|---|---|---|
| 2023年末 | F-TYPE、XF、XEの受注終了。2025年からBEV専売へ移行と発表 | MarkLines／各紙 |
| 2024年11〜12月 | リブランド「Copy Nothing」、新ロゴ、コンセプトカー**Type 00**をマイアミで公開。旧来ファンから「名前だけのJaguar」「ブランドの葬式」と強い反発 | CAR Magazine, Fortune, The Conversation |
| 2025年 | 新車ラインナップがほぼ空白。欧州での登録台数が激減（2025年4月に前年比97.5%減の49台とする報道。ACEAデータ引用） | MarkLines |
| 2025年4月 | Jaguar Classicが、Eタイプのボディパネル約30点を新規再生産 | GoAuto, Carscoops |
| 2026年5月 | 新型4ドアEV GTの名称を**Type 01**と発表（1,000hp級、約13万ドル〜） | evo, Autoblog |
| 2026年6月 | Jaguar ClassicのC/Dタイプ・コンティニュエーションが日本初上陸。「Ralph's Coffee & Cars supported by Octane」で展示 | as-web |

JLR側の公式見解は「創業者ウィリアム・ライオンズは『Jaguarは何の模倣でもあるべきではない（a copy of nothing）』と考えていた」「我々は“ヘリテージブランド”ではなく“ヘリテージを持つブランド”だ」。
→ **メーカーは未来へ跳び、ヘリテージの日常的な担い手の席が空いた。** 同時にメーカー自身もClassic部門（部品再生産、コンティニュエーション）ではヘリテージを収益化しており、「古いJaguarの価値」は公式にも裏付けられている。

### 戦略的含意
- 「本物のJaguarは、もう新車では手に入らない」という**“終わりの物語”**が、メーカー自身の手で作られた（SR400の生産終了による熱狂と同じ構造。Step 3参照）。
- ただし**メーカー批判を軸にするのは悪手**。新Jaguarを好きになる人もいる。正解は「失われゆくものへの敬意」と「ライオンズの“Grace, Space, Pace”を今に継ぐ」というポジティブな語り方。
- 英国の論者も「リブランドが人々を一層クラシックJaguarへ押しやるだろう」と予想している（Heritage Car Insurance）。ただし**需要急増を示す定量データは現時点でない**。仮説として扱い、自社の問い合わせデータで検証する。

## 2-2. 個体・相場（日本）

| モデル | 国内相場の目安 | 出典・注記 |
|---|---|---|
| XJ（X300系、1994〜） | 平均120〜130万円前後。走行5〜7万kmがボリュームゾーン。総生産92,038台 | Motor-Fan 2026年10月 |
| XJ（X300/X308） | 支払総額150万円前後で流通が多い（V8中心） | くるまのニュース |
| X350系 | 平均150〜180万円前後（流通30〜40台程度） | Motor-Fan |
| XJS | 英国で程度の良いクーペが個人売買で£5,000〜8,000、専門店物は£30,000超。「価値上昇中」 | Honest John Classics |
| XJ全般（欧州） | 2024年〜2026年1月で概ね安定。価値を決めるのは世代、エンジン、オリジナリティ。**記録の揃ったオリジナル車は値を保つ** | Classic Trader |

**読み解き**
1. **入口価格は軽自動車並み。** X300系なら100万円台前半から買える。「ドイツ車に飽きたら狙うべき“格安”セダン」という報道もある。若い世代の入口条件（手が届く本物）を満たしている。
2. 一方で、**安い個体ほど整備の“負債”を抱えている**。購入価格より整備費が高くつき、「壊れる」という評判を再生産する悪循環がある。
3. 欧州では「記録が揃ったオリジナル車」が値を保つ。**来歴（プロヴナンス）が価格を決める時代**。オーナーズインタビュー、整備記録、アーカイブはここに直結する。

## 2-3. 部品・技術

- Jaguar Classic Partsの対象範囲：X300（6／12気筒）、XJS、シリーズ3 XJ12、XJ6、XJ8（X308）、XJ40、デイムラー・リムジン（〜1992）。XJ（S3）とXJSで2万1,000点超の部品番号と、オリジナル図面を保有。
- 金型300点超を回収し、XJSのボンネットなどを再生産。ただし「どのモデルも100%の部品供給は現実的ではない」（2017年 JEC議事録）。
- 公式eBayストアなど、純正部品へのアクセスも改善中（2023年）。
→ **部品は「ある程度は手に入る」。本当のボトルネックは、それを組める技術者と、診断の知見。** 30年の専門店の知見がここで効く。

## 2-4. コミュニティの現状（日本）

- 「ジャガー・カー・クラブ・オブ・ジャパン」が2005年に横浜赤レンガ倉庫で「ジャガー・デイ2005」を開催（約100台）。**現在の活動は検索で確認できず**、少なくとも外から見える形の発信は弱い。
- フェラーリ（FOCJ）やミニ（ジャパンミニデイ、約3,000台）と比べると、**クラシックJaguarの“集まる場”と“顔”はほぼ空白**。
- 一方、Octane誌やRalph's Coffee & Carsのような**ライフスタイル型のクラシックカーイベント**は日本でも動いている。単独のワンメイクより「英国車／クラシック全体」の文脈の方が、母数の小ささを補える。

## 2-5. SWOT（暫定）

| | |
|---|---|
| **強み** | 美しさ（Eタイプ、XJのプロポーション）、英国紳士のイメージ、手頃な入口価格（X300/XJS）、30年の整備知見、メーカーの部品再生産 |
| **弱み** | 「壊れる」「おじさんの車」という評判。国内オーナーの分散。集まる場と顔の不在。母数の小ささ |
| **機会** | リブランドが生んだ“終わりの物語”。若年層のアナログ志向（YouTube/Instagram経由）。国産旧車の高騰で輸入クラシックが相対的に割安に。来歴重視の市場トレンド |
| **脅威** | 旧車重課の税制。整備士の高齢化と不足。安い個体による悪評の再生産。新Jaguarとの混同（ブランドイメージの希薄化） |
