# 戦略：洗車×オーナーズインタビュー

作成：2026-10-31（決定事項を反映）
関連：[operations.md](operations.md)（運用手順）／[consent_form.md](consent_form.md)（同意書）／[research_summary.md](research_summary.md)（根拠となる調査）

## 1. 結論

Jaguarオーナー向けの徹底洗車サービスと、YouTubeの「洗車×オーナーズインタビュー」企画を組み合わせて始める。

狙いは次の3つ。

1. 動画で新しいお客様を集める
2. コアオーナーとの接触回数を増やす
3. 整備・乗り換え・買取の相談につなげる

既存の設備と人員、スマートフォンで始められる。サイトの改修や新しい設備投資はしない。

## 2. 前提

| 項目 | 内容 |
|---|---|
| 運営 | 3名。本人（戦略・顧客管理）、兄（企画・撮影・編集）、父（洗車の監修・点検・オーナー対応・インタビューの聞き手） |
| 予算 | 小さく始める。サイト改修と設備投資はしない |
| 対象 | Jaguarのオーナー |
| 店の強み | クラシックJaguarの販売・整備・修理で30年以上の実績 |
| 保険 | 預かった車の事故に備える保険に加入済み |

## 3. 施策の内容

### 3-1. サービスと価格

| 項目 | 内容 |
|---|---|
| メニュー | 徹底洗車のみ。コーティングと研磨（磨き）は行わない |
| 価格 | 30,000円 |
| 出演特典 | インタビューに出演すると、レザーの手入れを無料で追加する |
| 2回目以降 | 出演したオーナーにも、3〜4ヶ月ごとに次の洗車を案内する |

### 3-2. 動画の構成（2段構造）

| 段 | 内容 | 主な視聴者 | 役割 |
|---|---|---|---|
| 1段目 | 洗車のビフォーアフター、作業の様子、愛車紹介 | 車好き、洗車動画の視聴者 | 再生数と新しい視聴者を集める |
| 2段目 | オーナーへのインタビュー（仕事、この車を選んだ理由、若い人に伝えたいこと） | 一般の視聴者、将来の買い手 | どんな人がJaguarに乗っているかを伝え、信頼と憧れをつくる |

1台の撮影から、長尺動画1本（12〜20分）とショート動画3〜4本を作る。

### 3-3. 営業へのつなげ方

```
洗車の予約 → 洗車・撮影・インタビュー → 動画公開 → 視聴者から新しい予約
                  │
                  ├─ 洗車中に父が車を点検 → 気づいた点を報告 → 整備の受注
                  │
                  └─ インタビューで「次に乗りたい車」「手放す予定」を聞いて記録
                        ├─ 3〜4ヶ月後に次の洗車を案内（接触回数が増える）
                        └─ 条件に合う車が入ったら個別に連絡（乗り換え・買取）
```

## 4. この施策を選ぶ理由

| 理由 | 根拠 |
|---|---|
| 費用が小さい | 既存の設備、人員、スマートフォンで始められる。サイト改修が不要 |
| 洗車動画は再生されやすい | ビフォーアフターと作業音がYouTubeと相性が良いジャンルとされる。国内では、社員10人ほどの洗車専門店が洗車動画で登録者約10万人を集め、全国から来店客を得た例がある |
| 若い層に届く経路と一致する | 米国の調査で、Z世代がクラシックカーと接点を持つ場はYouTube（39%）とInstagram（38%） |
| 繰り返し会う理由ができる | インタビューは1回だが、洗車は季節ごとに利用される |
| 整備の受注につながる | 洗車中は車の隅々まで見える。点検結果を報告すれば、売り込まずに整備を提案できる |
| 車の記録が残る | 欧州の市場では、記録の揃ったオリジナル車が値を保つと報告されている。動画と点検記録が、その車の記録になる |
| Jaguarに絞る | 専門店としての一貫性が保てる。父の知識を動画で最も生かせる |

数字と出典は [research_summary.md](research_summary.md) を参照。

## 5. 必ずやること（リスク対策）

| 項目 | 理由 | 対応 |
|---|---|---|
| 出演の同意書 | 映像の使い方で後から揉めないため。車を売る時に動画を使うには事前の同意が要る | [consent_form.md](consent_form.md) に署名をもらう |
| 作業前の記録 | 預かった車の状態を、後から確認できるようにするため | 作業前に車の傷を写真で記録し、オーナーと共有する（保険は加入済み） |
| 塗装の保護 | 古い車は塗装が薄い場合がある | 研磨とコーティングは行わない。薬剤は目立たない場所で試してから使う |
| 個人情報 | 出演者の身元や自宅が特定されないようにするため | ナンバー、自宅、勤務先をぼかす。職業は一行のテロップのみ |
| PR表記 | 景品表示法のステマ規制（2023年10月施行） | 出演者が自分のSNSで紹介する場合、出演特典を受けているので「PR」と表記してもらう |

## 6. やらないこと

| 施策 | 理由 |
|---|---|
| コーティング・研磨 | 磨きが必要で、古い塗装を傷めるリスクがある |
| Jaguar以外の車の受け付け | 当面はJaguarに絞る |
| サイトの改修 | 工数が大きい。まずこの企画に集中する |
| 維持費の公開 | 実際の費用が公開額を上回った場合に信頼を損なう。費用は個別の相談で伝える |
| オーナーの集まり、オーナー同士のコミュニティ | 忙しい人にはメリットが小さい。運営の負担が大きい |
| イベント開催、業界団体との取り組み | 3名では手が回らない |
| 新しいパッケージ商品 | 洗車でお客様との接点が増えてから検討する |

## 7. 進め方（最初の90日）

| 時期 | やること | 担当 |
|---|---|---|
| 1〜2週目 | 同意書と案内文を用意する。撮影機材（スマートフォン、ピンマイク、三脚）をそろえる | 本人・兄 |
| 3〜4週目 | 在庫のJaguarで試しに1本撮る（出演者なしで撮影と編集の流れを確認。在庫車の紹介にもなる） | 兄・父 |
| 2ヶ月目 | 出演オーナーの洗車2台。動画を公開する | 全員 |
| 3ヶ月目 | 出演オーナーの洗車2台。8章の数字で3ヶ月を振り返る | 全員 |

ペースは月2台。長尺動画2本とショート動画6〜8本になる。

## 8. 測る数字（毎月）

| 区分 | 数字 |
|---|---|
| サービス | 洗車の件数、うち出演の件数、2回目以降の予約の件数 |
| 動画 | ショートの再生数、長尺の再生数と視聴維持率、チャンネル登録者数 |
| 営業 | 動画を見て来た問い合わせの件数、洗車から受注した整備の件数、乗り換え・買取の相談件数 |

3ヶ月後に、続けるか、やり方を変えるかを判断する。

## 9. 決定事項

| 項目 | 決定 |
|---|---|
| メニュー | 徹底洗車のみ（コーティング・研磨は行わない） |
| 出演特典 | 徹底洗車にレザーの手入れを追加 |
| 保険 | 加入済み |
| 対象 | 当面はJaguarに絞る |

**後で決めること**

| 項目 | 決める時期 |
|---|---|
| 最初の出演者 | 在庫車での試し撮り（3〜4週目）が終わってから |
| 引き取り・納車を行うか | 出演オーナーの洗車を始める前（2ヶ月目まで） |
