# Step 6 — 事業戦略／業界戦略：コミュニティファーストの継承モデル

## 6-1. 戦略ステートメント

**ビジョン**：クラシックJaguarを、次の世代へ継ぐ。

**ポジション**：日本におけるクラシックJaguar文化の**記録者（Archivist）**であり**伴走者（Partner）**であり**主催者（Host）**。

**勝ち方**：
1. **来歴を記録する**ことで、良い個体の価値を正しく可視化する
2. **所有の不確実性をなくす**ことで、新しい世代が安心して入ってこられるようにする
3. **オーナーを主役にする**ことで、広告ではなく語りで需要を生む

**やらないこと**：値上がりを煽る（投機化）。成功を誇示する演出。新Jaguarを批判する。匿名の口コミ工作。在庫数と価格での勝負。

## 6-2. フライホイール

```
          ┌──────────── ⑥ 継承（買取・委託・次のオーナーへ）────────────┐
          │                                                               ▼
 ⑤ 記録（来歴・整備記録・オーナーの声）                   ① 物語（オーナーが語る・図鑑・映像）
          ▲                                                               │
          │                                                               ▼
 ④ 伴走（1年目プログラム・定額整備・仲間）               ② 遭遇と憧れ（ショート動画・街中・イベント）
          ▲                                                               │
          └──────────── ③ 安心の入口（維持費の見える化・入門パッケージ・LINE相談）◄─┘
```

- **起点は①ではなく⑤（記録）**。記録がなければ物語は嘘になり、継承の価値も生まれない。
- このループのどこにお金が落ちるか：③（車両販売）、④（整備と定額プラン）、⑥（買取・委託手数料）。①②⑤は**無料の接点**（Hagerty型）として投資する。

## 6-3. 三層の戦略

### 第1層：事業戦略（M-GARAGEが当事者として稼ぐ仕組み）

### 第3層：業界戦略（運営者を明示した「第三者的」な公共財）

| 施策 | 内容 | 狙う課題 | 熱源 |

## 6-4. 「当事者」と「第三者的」の使い分け

| | 当事者（M-GARAGE） | 第三者的（界隈の公共財） |
|---|---|---|
| 名乗り | M-GARAGEとして | 独立した名前で運営し、**運営者がM-GARAGEであることを明示**する（例：「運営：エムガレージ」） |
| 目的 | 販売、整備、伴走、継承 | 界隈全体の信頼と規模を作る |
| 施策 | B1〜B7、C1〜C7 | I1〜I5 |
| ルール | 本業の宣伝をしてよい | **本業の宣伝をしない**（自社在庫の誘導をしない）。他店の個体も平等に扱う |

**法令遵守**：ステマ規制（景品表示法、2023年10月施行）では、事業者の表示であることが判別困難な表示は違法になる。クリエイターや出演者に依頼・提供した投稿には必ずPR表記を付けてもらう。「一般のファンを装った投稿」は一切しない。
**商標**：「Jaguar」はJLRの登録商標。イベント名やレジストリ名に使う場合は、公式と誤認されない表現にし、必要に応じて権利者へ確認する。

## 6-6. KPI設計

**北極星指標**：**来歴が記録されたJaguarの台数**（アーカイブとレジストリの登録数）。記録が増えるほど、物語・信頼・継承のすべてが強くなるため。

| 段階 | 先行指標 | 結果指標 |
|---|---|---|
| 遭遇・憧れ | ショートの視聴数、保存数、ハッシュタグ付きの第三者投稿数 | 20〜30代のフォロワー比率 |
| 検討 | 維持費ページの閲覧、LINE相談数（特に「動画を見て」） | 相談からの来店率 |
| 購入 | 入門パッケージの問い合わせ数 | 新規オーナー数、P1・P2の比率 |
| 伴走 | 1年目プログラムの完了率、定額プランの加入率 | **1年以内の離脱率**（V5型の離脱を減らす） |
| コミュニティ | 朝の集まりの参加台数、**初参加者比率（目標30〜40%。軽井沢は41%）** | サークルのアクティブ率 |
| 継承 | 来歴記録の付いた再販台数 | 記録あり／なしの成約価格差と成約日数 |

## 6-7. リスクと対策

| リスク | 内容 | 対策 |
|---|---|---|
| 投機化 | 相場が上がりすぎると若者が締め出され、投機筋が入る（Z1/Z2） | 「値上がり」を語らない。入口価格帯の在庫を必ず持つ |
| ステマ・信頼毀損 | 第三者を装った発信が発覚すると致命傷 | 運営者の明示、PR表記の徹底、社内ルール化 |
| 顔への依存 | 発信者個人の炎上がブランドを毀損する（Petrolicious） | 顔は複数立てる。店のブランドと個人を分ける |
| 品格の崩れ | 成功の誇示や悪ノリで世界観が崩れる | トーン＆マナーの指針（美意識、敬意、ユーモアは自虐まで） |
| 運営負荷 | 少人数の店でイベントや発信が回らない | 小さく続ける（月1回、週1本）。連合で負荷を分ける。AI（本プラットフォーム）で記録と発信を省力化 |
| 母数の小ささ | Jaguar単独では集まらない | 英国クラシック全体で間口を開き、Jaguarで深さを出す |
| メーカーとの関係 | 公式との誤認や商標の問題 | 公式を尊重する姿勢。Jaguar Classicの部品やイベントは積極的に紹介し、協力関係を探る |
