## 補足：年表のタイトルは自動関連付けに使われている

`lib/related/auto.ts` が**タイトルに含まれる車種名**を手がかりに、
年表と在庫車両・図鑑を自動で結びつけている。
タイトルを編集する際、車種名（XJ / XK / Eタイプ 等）を消すと関連付けが切れる点に注意。

「XJ」の直後が英数字の場合（XJ220 / XJR）は別車種と見なす判定を入れているため、
2007年式XJの車両ページには X300／X350／X351型XJ の出来事が出て、
XJ220は出ない、という動きになる。

### ⚠️ 在庫実車との整合

**Eタイプは在庫に実車（3.8 OTS）があります。** 図鑑の「所有するということ」の記述と、
実際に販売している個体のコンディション説明が食い違うと、来店時に齟齬が出ます。
一度突き合わせておくことを推奨します。

### 構造の申し送り

XK120・XK140・XK150はいずれも独立した `model` としてブランド直下に並んでいます。
Mark IV/V や Mark VII/VIII/IX が1レコードに複数世代を束ねているのと不揃いです。
将来「車種：XK」の下に3シリーズをまとめ直すかは、設計判断として整理を推奨します。
