## 2. 未完了・要対応（ここから再開）

### ✅ 解決済み: 「更新が本番に反映されない」問題（2026-08-15 本番反映を確認）

**現在、本番は最新の状態です。**

原因は3つ重なっていた。いずれも修正済み。

1. **Vercelのデプロイが全て拒否されていた（真因）**
   `vercel.json` のCronを毎時（`0 * * * *`）で登録していたが、Hobbyプランは
   1日1回より高頻度のCronを許可しない。Vercelがデプロイを丸ごと拒否しており、
   **ビルドすら開始されていなかった**ため、ビルドログにも痕跡が残らなかった。
   → `0 0 * * *`（毎日09:00 JST）に変更して復旧。
2. **公開ページの内容がビルド時に固定されていた**
   トップ・ブログ一覧・図鑑一覧・オーナーズアーカイブ一覧・ランキングの5ページが
   静的生成され、管理画面で編集しても次のデプロイまで反映されなかった。
   → 各ページに `export const dynamic = "force-dynamic"` を追加。
3. **環境変数が1つ欠けるとビルド全体が落ちた**
   `Error: supabaseUrl is required.` としか出ず原因を特定できなかった。
   → 未設定の変数名と設定場所を名指しするエラーに変更（`lib/supabase/admin.ts`）。
   `app/sitemap.ts` はDB取得に失敗しても静的URLのみに縮退してビルドを止めない。

**確認方法**（今後また疑わしいとき）:

```bash
curl -s -o /dev/null -w "%{http_code}" -X POST https://mugengarage.vercel.app/api/admin/manufacturers
```

`401` ならデプロイ済み（認証エラーはルートが存在する証拠）。`404` なら未反映。

## 5. 開発時のメモ

### この環境の注意点

- `python` は使えない。スクリプトが必要なら `node` を使う
- DBのマイグレーションは自動適用されない。SQLを書いたら
  **ユーザーがSupabaseのSQL Editorで手動実行する**必要がある
- 検証用に流したテストデータ（テスト車両・テストメーカー）は削除済み

```bash
npx tsc --noEmit    # 型チェック
npm run lint        # Lint（警告6件は既知・react-hook-form関連で無害）
npm run test        # テスト（7件）
npm run build       # 本番ビルド
```
