## 2. 最初に触ってほしいもの

### 管理画面 > 運用 > 「画面を見ながら直す」

一番のご要望だった機能です。

- 左にお客様に見えている画面がそのまま出ます
- **点線で囲まれている場所をクリック**すると、右に入力欄が出ます
- 保存すると、左の画面がその場で描き直ります
- リンクを押せば、いつもどおりページを移動できます。直したいページまで進んでから押してください

いま直せるのは、車両の説明文・価格・年式・走行距離・エンジン等、記事のタイトルと本文、
図鑑・ライブラリ・年表の本文、店舗情報、そして**車両の写真の追加**です。

写真は、写真が1枚も無い車両の「写真は準備中です」の枠を押しても追加できます。
並び替え・削除・トリミングは従来どおり車両の編集画面で行えます。

> 公開ステータス（公開中／売約済）とURLは、この画面からは変えられないようにしています。
> クリック1つで公開状態が変わると事故になるためです。従来の編集画面で操作してください。

5分類（新着入庫（車紹介）／購入ガイド／整備記録／技術解説／トリビア・豆知識）に

| 記事                                     | 旧カテゴリ        | 新カテゴリ       |
| ---------------------------------------- | ----------------- | ---------------- |
| 初めてのクラシックジャガー 車種選びガイド | 購入ガイド        | 購入ガイド       |
| XKエンジン物語                           | 技術解説          | 技術解説         |

| クラシックJaguarの魅力とは               | （未設定）        | トリビア・豆知識 |

**歴史・ブランドの読み物3本が「トリビア・豆知識」に寄ります。**
いただいた5分類に素直に当てはめるとこうなりますが、
「歴史」のような分類を足したほうが自然であれば、そう言ってください。
カテゴリは管理画面のプルダウンから選び直せます。

### ② 「ジャガーを知る」に出す車種

/jaguar は図鑑の本文から、ブランド編＋車種3件＋エンジン2件を引用して構成しています。
**どの車種が出るかは図鑑の並び順（display_order）で決まります**ので、
「最初に読ませたいのはEタイプではなくMark 2だ」といった判断は、
図鑑の並び順を変えるだけで反映できます。コードの修正は不要です。

### ③ 並び替えの名前

いただいた言葉のまま「排気量が多い順」「走行距離が短い順」にしています。
中古車サイトの一般的な表記は「排気量が大きい順」「走行距離が少ない順」です。
揃えたい場合はお知らせください。

## 4. 昨夜直したもの

### 車両が保存できなくなる不具合（ご報告いただいた件）

「動画URLを入れないと更新できない」件は8/15に一度直していましたが、
**同じ症状を起こす経路がもう1つ残っていました**。

- 車検・法定整備・リサイクル料金・ハンドルの4つを「未設定」に選び直すと、
  保存を押しても**何も起きない**状態になっていました
- 車検満了日を入れてから消した場合も、保存だけが失敗していました

原因を塞いだうえで、**保存が止まったときは必ず画面に理由が出る**ようにしました
（画面下の保存ボタンの真上に、問題のある項目名が日本語で出ます）。
また、フォーム全体でブラウザ標準の入力チェックを使わないようにしたので、
「動画URLを入れないと保存できない」形の不具合はもう起きません。
