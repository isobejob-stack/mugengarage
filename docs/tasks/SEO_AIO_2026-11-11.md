# SEO・AIO（AI検索）対策の点検と実装（2026-11-11）

## 依頼

> SEO滅茶苦茶強くしたくて、ほかのエムガレージという会社とか、ジャガーなどの車屋さんで絶対に負けない奴にしてほしい。
> 対策は十分にできている？ ほかの会社の様子とか見たり、AIOの観点で考えたりとかしながら全力で検討してほしい。

## 結論

**サイトの中身（コンテンツ130件超・構造化データ・サイトマップ）は、競合の専門店よりかなり進んでいる。
足りなかったのは「この店が何者で、どこにあって、何の専門か」を検索エンジンとAIに正しく伝えること**と、
**サイトの外での存在感**（Googleビジネスプロフィール・Bing・掲載媒体からのリンク）。

前者はコードで直した（下の「実装したこと」）。後者は店側の操作が必要（下の「店側でやること」）。

なお「絶対に負けない」は約束できない（順位はGoogleが決める）。現実的な目標は次のとおり。

| 検索のされ方 | 目標 | 主な手段 |
| --- | --- | --- |
| 「エムガレージ ジャガー」「M-GARAGE ジャガー」 | 1位・ナレッジパネル | 構造化データ（実装済み）＋ Googleビジネスプロフィール |
| 「ジャガー 専門店 神奈川」「ジャガー 修理 川崎」 | 地図枠（ローカルパック）と上位 | Googleビジネスプロフィール・口コミ・整備事例 |
| 「ダブルシックス 中古」「XJ40 中古」など車種名 | 上位〜中位（グーネット・カーセンサーには勝ちにくい） | 車両ページの見出し（実装済み）・図鑑・整備事例 |
| AIの回答（Google の AI による概要、ChatGPT、Perplexity） | 「川崎のジャガー・ディムラー専門店」として公式サイトが出典になる | 構造化データ・llms.txt・Bing登録・IndexNow（実装済み）＋ 店舗情報の一貫性 |

## 調べたこと

### 検索・AIから見た今のエムガレージ

Web検索（Google日本版ではない検索エンジン。実際のGoogleの順位とは違う）で「エムガレージ」「ジャガー 専門店 神奈川」
「ジャガー 修理 川崎」を調べた。AIがまとめた回答はどれも**車選びドットコム・グーネットの掲載情報だけを根拠にしており、
「店舗の公式サイトは確認できませんでした」**と書かれていた。

- 住所（川崎市宮前区初山1-3-2）・営業時間（11:00〜19:00）・定休日（土曜）は掲載媒体から拾われている
- 電話番号は掲載媒体ごとに違う（グーネットは転送番号 0078-…、車選びドットコムは携帯）。AIは「掲載元によって異なる」と書いている
- 店の名乗りは「ジャガー・ディムラー専門店」「ジャガー・ダイムラー専門店」と、AIによって表記が揺れていた
- 「在庫は小田原のモータープールに保管、現車確認は事前に電話」という案内が拾われている

※ 本番サイト・競合サイトのページは、この作業環境のネットワーク設定で直接開けなかった。上は検索結果の要約から読み取ったもの。

### AIO（AI検索）で効くこと

- Google の AI による概要：特別な設定は不要で、通常の検索と同じ土台（索引に載っていること・役に立つ内容）。
  そのうえで「事業者の実体が明確か」（構造化データ・Googleビジネスプロフィールとの一貫性）が効くとされる
- ChatGPT の検索・Microsoft Copilot：**Bing の索引**が土台。Bing Webmaster Tools への登録と IndexNow が推奨されている。
  ローカルの回答では、事業者の公式サイトが最大の出典（約6割という調査あり）
- AIのクローラーは JavaScript を実行しないものが多い。このサイトはサーバー側でHTMLを出しているので問題ない

| 内容 | 場所 |

| トップのタイトルを「エムガレージ｜ジャガー・ディムラー専門店｜神奈川県川崎市」に。説明文も実態（XJ6・XJ-S・ダブルシックス、デイムラー表記）に合わせた。以前は「クラシックJaguar専門店／Eタイプ・XK・Mark2」で在庫と食い違っていた | `app/layout.tsx` |

| 車両ページの説明文を、年式・走行距離・支払総額・修復歴・ハンドル・車検の事実から作るようにした。以前は「**XJ6-3.2…**」とMarkdownの記号付きで出ていた | `lib/seo/vehicle-meta.ts` |

## 店側でやること（優先度順）

1. **Googleビジネスプロフィールの登録・確認**（最優先。「ジャガー 専門店 神奈川」の地図枠とAIの回答に直結）
   - https://business.google.com で「エムガレージ」を検索し、無ければ作成、あれば「オーナー確認」
   - ビジネス名は「エムガレージ」（キーワードを足すとGoogleの規約違反になる）
   - カテゴリ：メイン「中古車販売店」、追加「自動車整備工場」
   - 住所・営業時間・定休日・電話・**ウェブサイト（https://mugengarage.vercel.app）**・写真（店舗外観・在庫車）
   - 納車したお客様に口コミをお願いする（口コミの数と返信が地図枠の順位を左右する）
2. **Bing Webmaster Tools に登録**（ChatGPT・Copilot 対策。5分）
   - https://www.bing.com/webmasters で Microsoft アカウントでログイン →「Google Search Console からインポート」
   - これで確認・サイトマップが自動で引き継がれる。以後の更新は IndexNow で毎日自動送信される
3. **掲載媒体とInstagramから公式サイトへリンクする**
   - 車選びドットコム・グーネットの店舗ページの「ホームページ」欄、Instagramのプロフィールのリンクに公式サイトのURLを入れる
   - AIが「公式サイトは確認できませんでした」と答えている原因の一つ
4. **店舗情報の書き方をそろえる**（管理画面 > 設定 > 店舗情報・リンク）
   - 営業時間は「11:00〜19:00」、定休日は「土曜日」のように書くと、曜日ごとの営業時間として構造化データに出る
     （「平日は〜、土日は〜」のような書き方は読めないので出さない）
   - 「掲載媒体・公式SNS」に Instagram・車選びドットコムの店舗ページ・グーネットの店舗ページを入れる（同じ店だと結び付けるため）
   - 電話番号は、Googleビジネスプロフィールと同じ番号に
5. **独自ドメイン（m-garage.com）への移行**（ISSUE-003）。`*.vercel.app` のままでも検索には載るが、店のドメインのほうが信頼と指名検索に強い。
   移行するなら早いほど、積み上がった評価の引っ越しが小さく済む

## 次にやると効く中身（店主の知識が要るもの）

- **整備・修理の実例**（症状 → 原因 → 作業 → 費用の目安、写真つき）。「X300 オーバーヒート」「ダブルシックス 故障」のような検索と、
  AIの回答の出典になりやすい。競合の強みでもあるので、ここで並ぶと差がつく。ブログの「整備記録」カテゴリで書ける
- **よくある質問**（現車確認は予約制か・小田原の保管場所・遠方納車・ローン・保証・買取の流れ）。AIが答えを抜き出しやすい形。
  答えは店の方針なので、店主に確認してから載せる
- **代表者の紹介**（30年の経歴、得意な車種）。誰がやっている店かが分かると、検索エンジンの評価（経験・専門性）にも効く
- **図鑑の不足**：在庫の中心である XJ40・ディムラー ダブルシックス の解説（「XJ40 中古 注意点」「ダブルシックス 維持費」）
