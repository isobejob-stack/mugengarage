# 02_functional_requirements.md — 機能要件

## 1. Purpose（目的）

01_business_requirements.md で定義したビジネス要件を、「システムが提供すべき具体的な機能」に分解する。各機能にはFR-ID（Functional Requirement ID）を付与し、以降のDB設計・API設計・画面設計から参照可能にする。

## 2. Scope（対象範囲）

初期リリースに含める機能をドメインごとに列挙する。将来対応項目（01の8章）はここには含めない。

## 3. FR-ID命名規則

`FR-[ドメイン略称]-[連番]` とする。ドメイン略称一覧：

| 略称 | ドメイン                               |
| ---- | -------------------------------------- |
| INV  | Inventory（在庫管理）                  |
| VEH  | Vehicle Detail Page（車両詳細ページ）  |
| SRCH | Search（検索）                         |
| FAV  | Favorites（お気に入り）                |
| BLOG | CMS/Blog                               |
| ENC  | Jaguar Encyclopedia（図鑑）            |
| TL   | Timeline（年表）                       |
| LIB  | Library（ライブラリ）                  |
| MNT  | Maintenance Records（整備実績）        |
| OWN  | Owners Archive（オーナーズアーカイブ） |
| CRM  | CRM（顧客管理）                        |
| INQ  | Inquiry（問い合わせ）                  |
| LINE | LINE導線                               |
| SNS  | SNS連携                                |
| SEO  | SEO                                    |
| ADM  | Administration（管理画面共通）         |
| AI   | AI補助機能                             |

## 4. Inventory（在庫管理）

| ID         | 機能                       | 詳細                                                                             |
| ---------- | -------------------------- | -------------------------------------------------------------------------------- |
| FR-INV-001 | 車両新規登録               | 管理画面から車両情報・自由入力項目・写真・動画を入力し登録する                   |
| FR-INV-002 | 車両編集                   | 登録済み車両の全項目を編集できる                                                 |
| FR-INV-003 | 車両削除（論理）           | 物理削除は行わず、論理削除フラグで非表示にする                                   |
| FR-INV-004 | 公開ステータス変更         | 公開／非公開／売約済／商談中／Coming Soon を切り替える                           |
| FR-INV-005 | おすすめ／新着フラグ設定   | 一覧表示時の強調表示に利用するフラグをON/OFFできる                               |
| FR-INV-006 | 価格変更・履歴保持         | 価格を変更すると自動的に変更前価格・変更日時が履歴として保存される               |
| FR-INV-007 | 公開予約                   | 指定した日時に自動で「公開」ステータスへ切り替わる                               |
| FR-INV-008 | 一覧並び替え               | 管理画面の車両一覧をドラッグ&ドロップで任意の順序に並び替えられる                |
| FR-INV-009 | 写真アップロード・管理     | 1台につき複数枚（目安50枚程度、上限なし）の写真を追加・削除・順序変更できる      |
| FR-INV-010 | 動画登録                   | YouTube等の動画URLを車両ページに紐付けられる                                     |
| FR-INV-011 | 車両別SEO設定              | 車両ごとにTitle/Description/OGP/Slug等を個別設定できる                           |
| FR-INV-012 | 車両別タグ付け             | 自由なタグを複数付与できる                                                       |
| FR-INV-013 | グレード別テンプレート適用 | グレード選択時にエンジン説明・故障事例・維持費等を自動入力する（後述FR-VEH-004） |
| FR-INV-014 | 関連コンテンツ紐付け       | 関連記事／関連図鑑／関連ブログ／関連整備実績を車両に紐付けられる                 |

## 20. AI補助機能（初期リリース）

| ID        | 機能         | 詳細                                                   |
| --------- | ------------ | ------------------------------------------------------ |
| FR-AI-001 | 文章生成支援 | 車両説明文・ブログ記事草案等の生成を補助する           |
| FR-AI-002 | タグ提案     | 入力内容から適切なタグ候補を提案する                   |
| FR-AI-003 | SEO提案      | Title/Description等の改善案を提案する                  |
| FR-AI-004 | 関連記事提案 | 車両・記事等に紐付けるべき関連コンテンツ候補を提案する |

**注**：FR-AI系機能はすべて「提案」にとどめ、最終判断・確定操作は必ず管理者が行う。AIによる自動公開・自動診断は初期リリースでは実装しない。

## 21. Out of Scope（本ドキュメントの対象外）

- LINE API連携（自動応答等）
- CSV／外部API連携（グーネット、カーセンサー等）
- 多言語対応
- OCR
- 車両診断AI

## 22. Acceptance Criteria（本ドキュメントの受け入れ基準）

- [ ] 01_business_requirements.md の各ドメイン（4.1〜4.19）がすべてFR-IDとして機能分解されている
- [ ] 各FRが単一の責務を持ち、DB設計・画面設計にそのまま接続できる粒度になっている
- [ ] 業務ルール（論理削除・価格履歴保持・Vehicle非依存等）に反するFRが存在しない
