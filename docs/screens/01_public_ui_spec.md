# 01_public_ui_spec.md — 公開画面仕様

## 1. Purpose（目的）

00_screen_list.md で定義した公開画面（SCR-PUB-*）それぞれについて、画面内の主要要素・表示内容・操作を具体化する。デザインの詳細（配色・フォント等）は含まず、「何がどこにあり、何ができるか」の構造を定義する。

## 2. Scope（対象範囲）

SCR-PUB-001〜019（公開サイト全画面）を対象とする。共通のUIルール（ボタンサイズ・アクセシビリティ等）は 03_ui_rules.md を参照。

---

## 3. SCR-PUB-001 トップページ

**目的**：サイトの入口として、ブランドの世界観を伝えつつ、車両一覧・LINE相談・各コンテンツへ誘導する。

**主要要素**

- ヘッダー：ロゴ、グローバルナビ（在庫／図鑑／年表／ライブラリ／ブログ／整備実績／問い合わせ）、LINE相談ボタン（常設）
- ヒーローエリア：ブランドイメージ（英国／クラシック／重厚感を表現）
- おすすめ車両・新着車両（FR-INV-005のフラグが立った車両をカード表示）
- Jaguar図鑑・年表・ライブラリへの導線（ナレッジコンテンツの回遊を促す）
- 最新ブログ記事（3〜5件）
- 整備実績ピックアップ
- SNS（YouTube/Instagram）リンク
- フッター：店舗情報、各種リンク、LINE相談CTA（再掲）

## 4. SCR-PUB-002 車両一覧・検索結果

**目的**：条件を絞り込みながら車両を探す。

**主要要素**

- 絞り込みフォーム（FR-SRCH-001の全条件。スマホでは折りたたみ式アコーディオンを想定）
- 検索結果件数表示
- 車両カード一覧（サムネイル、車名、年式、走行距離、価格、ステータスバッジ：公開／商談中／Coming Soon等）
- ページネーション（pagination.md参照、デフォルト20件）
- 並び替え（新着順／価格順等）
- 検索条件はURLクエリパラメータで保持し、ブラウザバックでも維持される（FR-SRCH-003）

## 5. SCR-PUB-003 車両詳細

**目的**：1台の車両についてすべての情報を伝え、お気に入り登録・LINE相談・問い合わせにつなげる。

**主要要素**

- 写真ギャラリー（FR-VEH-003、スワイプ対応）
- ステータスバッジ（売約済・商談中・Coming Soon等）
- 基本情報テーブル（メーカー〜VINまでの全項目）
- 自由入力コンテンツ（販売コメント〜その他、Markdownレンダリング、見出しで区切って表示）
- お気に入りボタン（画面上部・下部の両方に配置し、スクロールしても押しやすくする）
- LINE相談CTA（常に画面下部に固定表示することを推奨、FR-VEH-007）
- 関連コンテンツ（関連図鑑・関連記事・関連整備実績のカード表示、FR-VEH-005）
- 動画（登録があれば埋め込み表示）
- 価格履歴（任意表示。値下げの経緯を信頼材料として見せる場合に使用）
- SEO：Title/Description/OGP/構造化データ（Product/Vehicle相当）を自動出力

## 6. SCR-PUB-004 お気に入り一覧

**目的**：ユーザーが自分の匿名セッションで登録した車両を振り返る。

**主要要素**

- お気に入り登録した車両のカード一覧
- 各カードから車両詳細へ遷移、お気に入り解除も可能
- 0件時は「気になる車両を探す」導線（車両一覧へ）を表示

## 7. SCR-PUB-005 人気ランキング

**目的**：お気に入り数を基準にした人気車両を見せ、購入検討の後押しをする。

**主要要素**

- ランキング形式のカード一覧（1〜10位程度）
- 売約済み・非公開の車両はランキング対象から除外する

## 8. SCR-PUB-006／007 ブログ一覧・詳細

**主要要素（一覧）**：カテゴリ・タグでの絞り込み、記事カード一覧（サムネイル・タイトル・抜粋・公開日）
**主要要素（詳細）**：Markdownレンダリングされた本文、関連記事・関連車両、SNSシェアボタン（任意）

## 9. SCR-PUB-008／009 Jaguar図鑑（一覧・詳細）

**主要要素（一覧）**：ブランド→シリーズ→車種→世代の階層をたどれるツリー型 or カテゴリタブ型のナビゲーション（FR-ENC-002）
**主要要素（詳細）**：本文（Markdown）、パンくずリスト（階層を明示）、該当する在庫車両があれば自動表示（FR-ENC-005）、対応する在庫車両がなくてもページとして成立する（BR-DOM-001）

## 10. SCR-PUB-010 Jaguar年表

**主要要素**：縦型タイムライン表示（スマホでのスクロール閲覧を想定）、カテゴリ別の色分け（モデル登場／エンジン登場／モータースポーツ／歴史）、年代での絞り込み、関連図鑑・記事へのリンク

## 11. SCR-PUB-011／012 ライブラリ（一覧・詳細）

**主要要素（一覧）**：五十音インデックス、カテゴリ絞り込み（FR-LIB-003）
**主要要素（詳細）**：本文（Markdown）、関連する用語集・図鑑・ブログへの相互リンク（FR-LIB-002）

## 12. SCR-PUB-013／014 整備実績（一覧・詳細）

**主要要素（一覧）**：カテゴリ（修理／レストア／整備）での絞り込み、カード一覧
**主要要素（詳細）**：故障事例・費用感・作業ポイント（Markdown）、関連車種・関連図鑑・関連ブログ・関連動画（FR-MNT-002）

## 13. SCR-PUB-015／016 オーナーズアーカイブ（一覧・詳細）

**主要要素（一覧）**：過去に販売した車両のカード一覧（現在の在庫とは視覚的に区別する）
**主要要素（詳細）**：写真、レストア履歴、販売履歴（Markdown）、将来的にオーナーコメント欄（現時点では非表示または準備中表示）

## 14. SCR-PUB-017 問い合わせフォーム

**主要要素**：相談カテゴリ選択（購入／修理／売却／部品／その他、FR-INQ-001）、氏名・連絡先入力、メッセージ本文、送信ボタン。フォーム上部にLINE相談への誘導も併記し、フォーム以外の選択肢も提示する（LINE最優先の方針、01_business_requirements.md）

## 15. SCR-PUB-018 店舗情報・アクセス

**主要要素**：店舗名、住所、営業時間、地図、SNSリンク、LINE相談CTA（静的コンテンツ、内容は運用者が管理画面から編集できる想定。詳細仕様は将来のIssueとして`docs/tasks/`に記録）

## 16. SCR-PUB-019 404ページ

**主要要素**：探している車両が売約済／削除された可能性を案内、車両一覧・トップページへの導線を提示し離脱を防ぐ（error_response.md 6章）

## 17. Acceptance Criteria（本ドキュメントの受け入れ基準）

- [ ] 全公開画面（SCR-PUB-001〜019）について、主要要素が具体化されている
- [ ] 02_functional_requirements.md の対応FR-IDが画面要素として過不足なく反映されている
- [ ] LINE相談CTA（01_business_requirements.md「最重要CTA」方針）が主要画面すべてに配置されている
