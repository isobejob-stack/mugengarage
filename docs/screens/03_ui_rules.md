# 03_ui_rules.md — UIルール（共通仕様）

## 1. Purpose（目的）

公開画面・管理画面すべてに共通して適用するUIルールを定義する。個別画面（01_public_ui_spec.md, 02_admin_ui_spec.md）で毎回同じ内容を繰り返さないよう、ここに集約する。

## 2. Scope（対象範囲）

レイアウト、アクセシビリティ、入力・操作、共通コンポーネントのルールを対象とする。配色・フォント・アイコン等の具体的なデザイントークンは、実装フェーズ（development/）でデザインシステムとして別途定義する。

## 3. レイアウト原則

- スマホファースト：まずスマホ幅（375px程度を基準）でレイアウトを設計し、PC表示はその拡張として扱う（00_project.md 7章）
- 主要な操作（登録・保存・公開切り替え等）ボタンは画面下部に固定表示し、スクロールしても押せる状態を保つ
- 情報量が多い画面（車両詳細・図鑑詳細等）はセクションごとに区切り、見出しでスキャンしやすくする（01_business_requirements.md「車選びドットコム」参考：情報量・詳細さ）

## 4. アクセシビリティ・視認性ルール

- 本文の基本文字サイズは16px以上を基準とする（高齢ユーザー配慮、03_non_functional_requirements.md 8章）
- タップ対象（ボタン・リンク）は最低44px四方のタップ領域を確保する
- 重要なボタン（LINE相談、お気に入り、公開切り替え等）はコントラストを高く保ち、周囲の余白を十分に取る
- 色だけで情報を伝えない（ステータスバッジは色＋文字ラベルの併記を必須とする。例：赤色だけでなく「売約済」の文字も表示）

## 5. 入力・フォームのルール

- 必須項目には「必須」ラベルを明示する
- 入力エラーはフィールドのすぐ下に赤字で表示する（error_response.md 6章と整合）
- 選択式で済む項目（メーカー・車種・グレード等の階層マスタ）は原則プルダウン／検索付きセレクトとし、自由入力を求めない（誤入力・表記ゆれ防止、BR-DATA-003）
- Markdown対応の自由入力欄には、プレビュー切り替えボタンを設置する（非エンジニアがMarkdown記法に迷わないよう、太字・見出し・リンク挿入等の簡易ツールバーを推奨）
- 長いフォーム（車両登録等）は自動保存または明示的な「一時保存」ボタンを用意し、入力途中の離脱でデータが消えないようにする

## 6. 画像・メディアアップロードのルール

- アップロード時は進捗（プログレスバー）を表示する
- アップロード後、自動的に圧縮・最適化される旨をUI上で意識させない（裏側で自動処理、03_non_functional_requirements.md 4章）
- 並び替えはドラッグ&ドロップに対応し、スマホでは長押し操作で開始する
- 1枚ずつの削除に加え、複数選択削除にも対応する（写真50枚規模の運用を想定）

## 7. ナビゲーション・共通コンポーネント

- **グローバルヘッダー**（公開サイト）：ロゴ、主要ナビ、LINE相談ボタンを常設
- **パンくずリスト**：階層構造を持つコンテンツ（図鑑・車両カテゴリ等）に必須設置（FR-SEO-006）
- **ステータスバッジ**：全ドメイン共通のバッジコンポーネントとして統一（車両ステータス、記事の下書き/公開、問い合わせの対応状況等で使い回す）
- **確認ダイアログ**：削除・ステータス変更等の取り消しにくい操作の前には必ず確認ダイアログを挟む。特に価格変更・公開ステータス変更・削除操作は文言で影響範囲を明示する（例：「売約済みに変更すると在庫一覧から非表示になります」）

## 8. 管理画面特有のルール

- 保存・更新操作後は、画面遷移せずその場でトースト通知等の即時フィードバックを返す（03_non_functional_requirements.md 4章「即座にフィードバック」）
- 一覧画面には必ず検索・絞り込みを用意する（データ件数が増えても運用者が迷わないため）
- 危険な操作（削除、ステータスを売約済に変更等）は、誤タップ防止のため一段階多く確認を挟む

## 9. Acceptance Criteria（本ドキュメントの受け入れ基準）

- [ ] 01・02の個別画面仕様と矛盾しない共通ルールとして整理されている
- [ ] 03_non_functional_requirements.md のアクセシビリティ要件（8章）が具体的なUIルールに落とし込まれている
- [ ] 非エンジニアの運用者が迷いやすいポイント（削除・ステータス変更・価格変更等）に対する安全策が明記されている
